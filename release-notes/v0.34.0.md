รุ่น 0.34.0: หน้าตาใหม่ที่อนุมัติแล้ว และเลือกภาษาไทย / English / 日本語

- เลือกภาษาที่ตั้งค่า (มือถือและคอม) เปลี่ยนแล้วแอปเปิดใหม่เอง ทุกหน้า บทเรียน และเพลงแปลแล้ว ชื่อทางเดินคอร์ดญี่ปุ่นมีโรมาจิกำกับ
- แถบเมนูมีแต่ไอคอน หน้าวันนี้ไม่มีหัวข้อและวันที่ คอมใช้โลโก้เดิมที่แถบข้าง
- เปียโนมินิมอล: คีย์แบน หน้าเปียโนเหลือสถานะ MIDI ปุ่มตั้งค่าเสียง โน้ตล่าสุด และคีย์
- ตั้งค่า: ซิงค์เหลือปุ่ม Sync ปุ่มเดียว (ครั้งแรกถาม GitHub token ครั้งเดียว) ไม่มีเมนูความเข้มจังหวะแล้ว
- ไม่มีเลขบท เลขด่าน L1 L2 และ "ระดับ 1 2 3" ระดับทักษะแสดงเป็นจุด ด่านแสดงเป็นชื่อ
- "ผ่านแล้ว" เป็นป้ายสีเขียว บทที่ยังไม่เปิดเป็นแถวสีเทา

ข้อมูลเดิมอยู่ครบ ควรอัปเดตทั้งมือถือและคอม ยังไม่ได้ตรวจบนเครื่องจริง
