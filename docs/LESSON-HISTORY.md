# ประวัติและพัฒนาการรายบท

เปิดบทเดิม แล้วเลื่อนไปที่ **ประวัติและพัฒนาการบทนี้** ใต้ปุ่มเริ่มฝึก
บันทึกผลอัตโนมัติเมื่อจบรอบ ไม่ต้องกดบันทึกซ้ำ เลือกชื่อแบบฝึกเพื่อกรอง และกดดูย้อนหลังเพิ่มครั้งละ 10 รอบได้

แต่ละรอบแสดงวันเวลา แบบฝึก มือ โหมด ความเร็ว และค่าที่วัดได้จริง เช่น โน้ตถูก จังหวะ สะดุด หรือจำนวนเปลี่ยนคอร์ด
โหมดรอไม่แสดงว่าจังหวะผ่าน เมื่อเปิดตัวช่วยจะแสดงแยกไว้ เกณฑ์ผ่านบทและผลทวนข้ามวันยังใช้กฎเดิม

การเทียบผลเลือกครั้งแรกกับครั้งล่าสุดของแบบฝึกที่เงื่อนไขตรงกัน: มือ โหมด ความเร็ว ช่วงฝึก เกณฑ์จังหวะ และแหล่ง input ที่บันทึก
ไม่นำรอบหยุดกลางคัน ไม่มี input หรือใช้ตัวช่วยมาสรุปเป็นพัฒนาการ การเพิ่มเปอร์เซ็นต์ในวันเดียวไม่ได้พิสูจน์การจำข้ามวัน
โน้ตที่ generator สร้างอาจต่าง seed ได้ แต่ต้องเป็นแบบฝึกและเกณฑ์เดียวกัน

เก็บข้อมูลในตาราง attempts เดิม ไม่มีการล้างฐานข้อมูล ประวัติเดิมยังแสดง แต่ถ้าไม่มี metadata ยืนยันว่าจบรอบจะไม่ใส่ในการเปรียบเทียบ
ผลเพลงเดิมที่ไม่ได้เก็บบทต้นทางยังเป็นผลเพลง ไม่เดาว่าเป็นบทใด การเปิดเพลงจากบทตั้งแต่รุ่นนี้จะส่งบริบทบทและแบบฝึกไปด้วย

รอบถามตอบที่ออกก่อนจบยังไม่สร้างผลสรุปใหม่ รอบอ่านที่กดหยุดหลังมีโน้ตตัดสินแล้วมีผลตามจริง และติดป้ายหยุดกลางคันหากยังมีโน้ตเหลือ
การฟังตัวอย่างหรือเพียงเปิดบทไม่สร้างความแม่นหรือผลผ่าน

## ขณะเล่น

เริ่มเล่นบรรทัดโน้ตแล้วแอปขอแนวนอนทั้งสองด้าน ซ่อน system bars และแสดงบรรทัดใหญ่พร้อมปุ่มหยุด
เมื่อต่อ MIDI พื้นที่ที่เหลือเป็นโน้ตทั้งหมด มือถือแสดงคีย์เฉพาะที่ต้องใช้ หมุนจอคืนตามนโยบายเดิมเมื่อหยุด/ออก
โน้ตไหลยังเลือกใช้ได้ทั้งสองแนว ไม่มีตัวเลือกขนาดกระดาษอีกต่อไป
