รุ่น 0.33.0: สาย piano solo (ระบบเรียนใหม่ ส่วนแรก) และซิงค์ใน repo เดียว

- ทักษะใหม่ "เล่นเดี่ยวสองมือ" 7 ระดับ: มือขวาเล่นทำนอง มือซ้ายเล่นรูปแบบประกอบ จากโน้ตรากยาวไปถึงซิงโคเพชัน 16 บีต คีย์ไต่จาก C ไป A♭ E♭ B♭ E ความเร็ว 60 → 100
  - แบบทดสอบตัดสินจังหวะ จึงต้องต่อสาย (ทำบนคอม)
  - เปิดเมื่อถืออ่านโน้ตใหม่ระดับ 5 และคอร์ดระดับ 1 ก่อนหน้านั้นหน้าทักษะบอก "ยังไม่เปิด" แต่กดทดสอบเองได้
- แผนวันนี้มีส่วน "สองมือแบบ piano solo" เมื่อทักษะนี้เปิดแล้ว ฝึกแบบรอ ไม่จับเวลา ใช้บนมือถือได้ เปิดจากหน้าทักษะได้ด้วย
- หน้าเป้าหมายนับระดับเล่นเดี่ยวที่แต่ละเพลงต้องการ (ค่าประเมิน)
- ซิงค์มือถือกับคอมผ่าน branch sync-data ของ repo mimikopi เดียว เพลงส่วนตัว เพลงเป้าหมาย และโน้ตที่ซื้ออยู่บนคอมเท่านั้น มือถือบอกให้ย้ายเพลงที่ยังอยู่บนมือถือไปคอม
- ไฟล์ติดตั้งและไฟล์อัปเดตอยู่ที่ Releases ของ repo mimikopi

ควรอัปเดตทั้งมือถือและคอมพร้อมกัน แอปรุ่นเก่าอ่านผลทดสอบของทักษะใหม่ไม่ได้ (ข้อมูลไม่เสีย แต่จะข้ามไฟล์ซิงค์ของอีกเครื่องจนกว่าจะอัปเดต)
บันได ระดับทักษะเดิม คลังเพลง และสอบเกรดทำงานเหมือนเดิม ข้อมูลเดิมอยู่ครบ ยังไม่ได้ตรวจบนเครื่องจริง
