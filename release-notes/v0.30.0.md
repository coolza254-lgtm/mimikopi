รุ่น 0.30.0: หน้าตาพาสเทลใหม่ โน้ตมาตรฐานอ่านง่าย โน้ตตกแบบวิดีโอสอน

- หน้าตามินิมอลพาสเทลขาว-ชมพูตามโลโก้ ปุ่มหลักสีชมพู ใช้โหมดสว่างเป็นค่าเริ่มต้น (เลือกโหมดมืดได้ในตั้งค่า)
- โน้ตแบบมาตรฐาน: แบบฝึกมือเดียวแสดงบรรทัดเดียว โน้ตใหญ่ขึ้นราวสองเท่า คานเขบ็ดเอียงตามทำนอง เลขนิ้วเรียงแถวเดียว ตัวหยุดเต็มห้องอยู่กลางห้อง เลขห้องไม่ปนเลขนิ้ว
- ระหว่างเล่น: กดถูก โน้ตเป็นสีเขียวมีวงแสงสั้น ๆ กดผิดมีกากบาทแดงตรงเสียงที่กดแล้วจางไป เร็วหรือช้าเกินเป็นสีเหลือง
- โน้ตตกแบบวิดีโอสอนเปียโน: พื้นมืด มือซ้ายฟ้า มือขวาเขียว ชื่อโด-เร-มีบนแท่ง เส้นตีสีแดง คีย์บอร์ดบอกชื่อเฉพาะโน้ตในคีย์ของเพลง และชื่อคีย์มุมซ้ายล่าง
- แผนวันนี้ไม่มีวอร์มนิ้วแล้ว เริ่มจากทวนโน้ตที่รู้แล้วก่อน ไล่จากง่ายไปยาก ค่าเริ่มต้น 20 นาที
- เอาการวัดความหน่วงออกจากหน้า MIDI ใช้ค่าที่เหมาะให้เอง ค่าที่เคยวัดไว้ยังใช้ต่อ
- หน้าฝึกเพลงคลีนขึ้น ตัวเลือกที่ไม่ค่อยใช้ย้ายไปไว้ใน "เพิ่มเติม"
- หน้าพัฒนาการมีตัวเลขสรุป 3 ช่องด้านบน (เวลาฝึกสัปดาห์นี้ ระดับรวม หู) พร้อมบอกว่าขึ้นหรือลงจากก่อนหน้า

ข้อมูลและประวัติการฝึกเดิมอยู่ครบ ใช้ไฟล์สำรองเดียวกับโปรแกรมบนคอม Windows ได้
ยังต้องตรวจเสียง MIDI และหน้าจอบนโทรศัพท์จริง
