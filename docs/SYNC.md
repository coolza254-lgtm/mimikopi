# ซิงค์มือถือกับคอมผ่าน GitHub

มือถือกับคอมรวมความคืบหน้ากันผ่าน repo ส่วนตัวบน GitHub (learning-system.md หัวข้อ 2.11)
แต่ละเครื่องเขียนไฟล์ของตัวเองใน `devices/` แล้วอ่านของอีกเครื่องมารวม จึงไม่มีการทับกัน
สิ่งที่ซิงค์: บทเรียน เพลงในคลัง ผลทดสอบระดับ ผลสอบ หู คอร์ด นาทีฝึก สิ่งที่ควรแก้ และรายการทบทวน
สิ่งที่ไม่ซิงค์: เพลงส่วนตัวและโน้ตที่ซื้อ (อยู่บนคอมเท่านั้น) โน้ตที่เขียนเอง ประวัติรายรอบ และค่าของเครื่อง (MIDI ชื่อเปียโน เสียง ธีม)

## ตั้งค่าครั้งเดียว

ใช้ repo `mimikopi` ที่เดียว (โค้ด ไฟล์ติดตั้ง และข้อมูลซิงค์) ข้อมูลซิงค์อยู่ใน branch `sync-data` ซึ่งแอปสร้างให้เองตอนซิงค์ครั้งแรก
repo นี้เป็น public จึงมีคนอื่นเห็นไฟล์ความคืบหน้าได้ (นาทีฝึก ระดับ ผลทดสอบ จุดที่ผิดบ่อย) เพลงส่วนตัวและโน้ตที่ซื้อไม่อยู่ในนั้น

1. **สร้าง token** ที่ github.com/settings/personal-access-tokens/new (Fine-grained)
   - Repository access: **Only select repositories** → `mimikopi` เท่านั้น
   - Permissions → Repository → **Contents: Read and write** (อย่างอื่นไม่ต้องเปิด)
   - Expiration เลือกได้ตามสะดวก เมื่อหมดอายุ แอปจะบอกว่า token ใช้ไม่ได้ ให้สร้างใหม่แล้วใส่อีกครั้ง
   - token นี้แก้ไฟล์ใน repo ได้ เก็บไว้ในเครื่องของตัวเองเท่านั้น อย่าส่งให้ใคร
2. **มือถือ:** ตั้งค่า → ซิงค์กับคอม → ช่อง repo เป็น `coolza254-lgtm/mimikopi` อยู่แล้ว ใส่ token → กด "บันทึกและซิงค์ตอนนี้"
3. **คอม:** ตั้งค่า → ซิงค์กับมือถือ → ใส่ token เดียวกัน → กด "บันทึกและซิงค์ตอนนี้"

ใช้ token เดียวกันทั้งสองเครื่องได้ token เก็บในไฟล์ของแต่ละเครื่อง ไม่อยู่ในฐานข้อมูล จึงไม่อยู่ในไฟล์สำรองหรือข้อมูลที่ซิงค์

## ใช้งาน

- ซิงค์เองตอนเปิดแอปหรือกลับเข้าแอป (มือถือ ไม่บ่อยกว่าทุก 2 นาที) และตอนออกจากแอปหรือปิดโปรแกรม
- กดซิงค์เองได้ที่หน้าตั้งค่า บรรทัดใต้ปุ่มบอกเวลาและผลล่าสุด
- ก่อนรวมข้อมูลจากอีกเครื่อง แอปสำรองข้อมูลอัตโนมัติก่อนทุกครั้ง (ชื่อไฟล์มีคำว่า `before-sync`)
- ไม่มีอินเทอร์เน็ตก็ฝึกได้ตามปกติ ซิงค์รอบถัดไปจะรวมให้เอง
- ส่วนในแผนวันนี้ที่ต้องต่อสาย (เช่นขั้นที่ตัดสินจังหวะ) ทำบนคอมแล้ว จะติ๊กในแผนของมือถือหลังซิงค์

## ถ้ามีปัญหา

| ข้อความ | ทำอย่างไร |
|---|---|
| token ใช้ไม่ได้หรือหมดอายุ | สร้าง token ใหม่ตามข้อ 2 แล้วใส่อีกครั้งทั้งสองเครื่อง |
| ไม่พบ repo หรือ token เข้าถึงไม่ได้ | ตรวจชื่อ repo (เจ้าของ/ชื่อ) และว่า token เลือก repo นี้ไว้ |
| token ไม่มีสิทธิ์เขียน | เปิด Contents: Read and write ให้ token |
| มีอีกเครื่องซิงค์พร้อมกัน | กดซิงค์อีกครั้ง |
