## ยังตรวจไม่สำเร็จ / ยังต้องลองบนมือถือ
Android 15 emulator (API 35) บนคลาวด์นี้ไม่มี `/dev/kvm` จึงใช้ software emulation
บูตไม่ครบในช่วงตรวจ มีข้อผิดพลาดภายใน Android ก่อนติดตั้งแอป (PackageManager/StorageManager ยังไม่พร้อม
และ Bluetooth system service ล้ม) จึงยังไม่ได้ยืนยันภาพทั้งสองธีมหรือ navigation ด้วยการกดจริง
ไม่ถือเป็นผลทดสอบว่าแอปผ่านหรือไม่ผ่าน UI; ไม่แก้แอปเพื่อกลบข้อผิดพลาดของ emulator

ลอง APK บนมือถือโดยติดตั้งแยกจากตัว release แล้วตรวจ:
1. Today เลือก 10/20/30 นาที เปิดแผนทั้งหมด ตรวจว่าผลรวมตรงและย้อนกลับมาเวลาฝึกยังอยู่
2. เปิดเพลงจากคลัง เล่นให้มีข้อผิดพลาดแล้วจบ ดูคำแนะนำหลักและรายละเอียดโน้ต
3. กดฝึกบาร์/แยกมือ: เริ่มรอบทันที บาร์ มือ และ bpm ตรงกับปุ่ม จากนั้นลองเล่นทั้งเพลงได้
4. เปิดทดสอบระดับ/สอบเกรด: เกณฑ์ยังคงเดิม ไม่มีปุ่มลดความยากเพื่อนับผลผ่าน
5. ปล่อยโหมดตามจังหวะจบโดยไม่กดคีย์: เพิ่มเวลาซ้อมเป็นศูนย์ ไม่บอกให้ลดความเร็วจากข้อมูลที่ไม่ได้เล่น
6. วัดความหน่วง: กดคอร์ดในคลิกเดียวไม่ควรผ่าน ต้องกดอย่างน้อย 10 คลิก; เปลี่ยน route แล้วค่าต้องแยกกัน
7. เปิดโน้ตไหล เล่นโหมดรอ/ตามจังหวะด้วย MIDI และคีย์หน้าจอ ลองคอร์ด กดผิด เร็ว/ช้า ปล่อยพลาด สลับชื่อขณะเล่น แล้วเปิดใหม่เพื่อตรวจค่าที่จำไว้
8. ตรวจหน้า Today และผลลัพธ์ในสองธีม แนวตั้ง/แนวนอน และขนาดตัวหนังสือที่ใช้จริง
