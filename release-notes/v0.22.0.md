รุ่น 0.22.0: เปิด/ปิดน้ำหนักคีย์ (Velocity) และแก้ปัญหาคีย์บอร์ดในรุ่น Windows
- สวิตช์ "น้ำหนักคีย์ (Velocity)": ปิดอยู่ตั้งแต่เริ่ม ทุกโน้ตดังเท่ากันไม่ว่ากดเบาหรือแรง เลือกระดับเสียงได้ (เบา / กลาง / ดัง) พอเล่นเป็นแล้วค่อยเปิดเพื่อฝึกน้ำหนักมือ มือถืออยู่ที่หน้าต่อเปียโน (MIDI) → การตั้งค่า, Windows อยู่ที่ตั้งค่า → เสียงเปียโน
- มีผลกับเสียงของแอพเท่านั้น ถ้าฟังจากลำโพงของเปียโนเอง ให้ปรับ Touch ที่ตัวเปียโน
- รุ่น Windows: แนะนำให้เปิดโปรแกรมก่อนแล้วค่อยเสียบสาย ถ้าเปิดคีย์บอร์ดได้แต่ไม่มีโน้ตเข้า หน้าตั้งค่าบอกวิธีแก้
- รายงานการเชื่อมต่อบอกเลขรุ่น Windows จำนวนข้อมูลทั้งหมดที่ได้รับ และผลการถามตัวตนเปียโน (จับคู่ช่องส่งของคีย์บอร์ดได้แล้ว)
- แท็บคอร์ดมีหมวด "วิธีจับคอร์ด": เลือกรากและชนิดคอร์ด แล้วดูภาพคีย์บอร์ดพร้อมเลขนิ้ว ทั้งแบบสองมือ (มือซ้ายกดราก มือขวากดคอร์ด) มือขวา (ตำแหน่งพื้นฐานและพลิกคอร์ด) และมือซ้าย กดฟังเสียงได้ทุกภาพ
