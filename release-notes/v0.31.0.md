รุ่น 0.31.0: ซิงค์มือถือกับคอม ต่อสายเมื่อวัดจังหวะ และ Badger Playon

- เปียโนชื่อ "Badger Playon" พร้อมรูปเปียโนเด็กสีชมพู เปลี่ยนชื่อเองได้ที่หน้าต่อเปียโน (คอม: ตั้งค่า → เปียโน MIDI)
- แบบฝึกที่ตัดสินจังหวะต้องต่อเปียโนด้วยสาย USB: บนมือถือที่ใช้บลูทูธหรือคีย์บนจอ แอปบอกให้ฝึกข้อนั้นบนคอม ส่วนอ่านโน้ต หาคีย์ ฝึกหู คอร์ด และโหมดรอยังฝึกได้ตามปกติ
- แผนวันนี้ชุดเดียวทั้งสองเครื่อง ส่วนที่ต้องต่อสายมีป้าย "ต่อสายก่อน (ฝึกบนคอม)" ทำบนคอมแล้วนับในแผนหลังซิงค์
- ซิงค์ความคืบหน้ากับคอมผ่าน repo ส่วนตัวบน GitHub ตั้งค่าครั้งเดียวที่ ตั้งค่า → ซิงค์กับคอมผ่าน GitHub ซิงค์เองตอนเปิดและปิดแอป สำรองข้อมูลก่อนรวมทุกครั้ง (วิธีตั้งค่าอยู่ใน docs/SYNC.md)
- คลังเพลงและการสอบเกรดกลับมาใช้ได้อีกครั้ง
- ถ้ากดถูกตัวแต่สูงหรือต่ำไปหนึ่งอ็อกเทฟหลายครั้ง แอปบอกให้หา C กลางก่อนวางมือ
- ไฟล์อัปเดตและชุดเสียงเปียโนย้ายมาอยู่ที่ repo mimikopi ที่เดียวกับโปรแกรมบนคอม

ข้อมูลและประวัติการฝึกเดิมอยู่ครบ ยังต้องตรวจชื่อเปียโน การซิงค์ และการต่อสายบนเครื่องจริง
