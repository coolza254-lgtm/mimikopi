รุ่น 0.18.0: ミミコピ สำหรับ Windows ครบ 4 แท็บ
- รุ่น Windows มี อ่านโน้ต (บันไดขั้นฝึก แบบฝึก และทบทวน) และ เพลง (เพลงฝึกที่ไม่มีลิขสิทธิ์ เลือกมือขวา มือซ้าย หรือสองมือ) แล้ว ครบเหมือนมือถือ: อ่านโน้ต ฝึกฟัง เพลง ฝึกท่อน
- หน้าอ่านโน้ตเพลงใช้แบบเดียวกับมือถือ: โหมดรอ และโหมดตามจังหวะพร้อมนับเข้า ฟังตัวอย่าง เลือกท่อนด้วยการคลิกบาร์ แอพเล่นมืออื่นให้ และดูแบบหน้ากระดาษได้
- เมโทรนอมในรุ่น Windows: เสียงคลิกจากเปียโนของโปรแกรม (แบบฝึกจังหวะคงที่และการนับเข้าใช้ได้)
- ความคืบหน้าของขั้นอ่านโน้ตและเพลงย้ายกับไฟล์สำรองได้ทั้งสองทาง (มือถือ ↔ คอม)
- ถ้าในโหมดตามจังหวะรู้สึกว่าโปรแกรมบอกว่า "ช้า" เท่าๆ กันทุกโน้ต อาจเป็นความหน่วงเสียงของคอมเครื่องนั้น ยังไม่มีหน้าวัดความหน่วงในรุ่น Windows
- แอพมือถือ: ไม่มีอะไรเปลี่ยน
- โปรแกรมไม่ได้เซ็นชื่อดิจิทัล ตอนติดตั้ง Windows อาจเตือน "Windows protected your PC" ให้กด More info → Run anyway
