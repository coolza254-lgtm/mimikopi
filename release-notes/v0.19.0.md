รุ่น 0.19.0: โหมดโน้ตตก (มือถือและ Windows)
- เพลง: มีปุ่ม "โน้ตตก" ในหน้าเล่นเพลง แท่งโน้ตตกลงมาบนคีย์บอร์ด ถึงเส้นเมื่อไรให้กด มีชื่อโน้ตบนแท่งและบนคีย์ คีย์ที่กดบนคีย์บอร์ด MIDI จะยุบลงให้เห็น ใช้ได้ทั้งโหมดรอ โหมดตามจังหวะ และปุ่มฟัง มือขวาสีขาว มือซ้ายสีเทา มือที่แอพเล่นให้เป็นเส้นขอบ
- รอบที่เล่นแบบโน้ตตกไม่นับเป็นการผ่านเพลง (เหมือนการเปิดชื่อโน้ต) เพราะไม่ได้อ่านโน้ตดนตรี สลับกลับเป็นโน้ตดนตรีได้ทุกเมื่อ
- ฝึกท่อน: สลับ "ตัวใหญ่ / โน้ตตก" ได้ที่หน้าฝึก ตกทีละโน้ตและรอให้กดถูก กดผิดจะเลื่อนกลับไปต้นวลี มีเส้นแบ่งวลี
- ใช้ได้ทั้งมือถือและรุ่น Windows (รุ่น Windows อัปเดตจากในโปรแกรมได้ที่ ตั้งค่า → อัปเดตโปรแกรม)
