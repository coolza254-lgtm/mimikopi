# สรุปส่งต่อ: ระบบการฝึกของ ミミコピ (2026-10-22)

เอกสารนี้สรุปสิ่งที่เปลี่ยนในระบบการฝึกจากแชทนี้ สถานะปัจจุบันของระบบ และสิ่งที่ยังขาด เพื่อส่งให้แชทที่ออกแบบระบบการเรียนใหม่
สเปกเต็มอยู่ที่ `docs/learning-system.md` (หัวข้อ 2.11 คือการตัดสินใจล่าสุด)

## 1. เป้าหมายและการตัดสินใจของผู้ใช้ (ล่าสุดชนะของเก่า)

- **เป้าหมาย:** เล่น **piano solo เพลง Hello! Project ได้หลายเพลง** (มือขวาเล่นทำนอง มือซ้ายเล่นรูปแบบประกอบ เล่นคนเดียว)
- **เพลงที่ชอบ:**
  - 心のプラカード (AKB48) เป็นเพลงไอดอลเพลงแรกที่ชอบ เก็บไว้เป็นเพลงประจำใจ
  - เป้าหลักยังเป็นเพลง H!P เช่น I WISH และ 恋愛レボリューション21
- **เส้นทางแบบ ค. (ผสม):**
  1. พื้นฐานอ่านโน้ต
  2. ซื้อโน้ต piano solo ระดับ 入門/初級
  3. แกะและเรียบเรียงเองด้วยหู
- **เลิกเรียนจากเพลงคลาสสิก (ตัดสินวันนี้):**
  - Heroic Polonaise ไม่ใช่เป้าหมายอีกต่อไป
  - หน้าเพลงไม่มีการ์ด Heroic แล้ว
  - **ยังค้างให้ตัดสิน:** คลังเพลงสาธารณะ 32 เพลง (เพลงพื้นบ้านและคลาสสิกง่าย) ยังใช้เป็นวัตถุดิบอ่านโน้ต บทเรียน และเพลงสอบเกรดอยู่ แชทออกแบบต้องเลือกว่าจะเก็บไว้เป็นแบบฝึกอ่าน หรือเปลี่ยนเป็นวัตถุดิบสไตล์ป็อป/ไอดอลที่แอปแต่งเอง
- **เพลงเป้าหมาย = เพลงส่วนตัวที่เลือกเอง** (ดูข้อ 2.4)
- **การแบ่งงานระหว่างเครื่อง:**
  - **คอม:** ต่อสาย USB เสมอ ทำทุกอย่างที่ตัดสินจังหวะ
  - **มือถือ:** ต่อบลูทูธหรือใช้คีย์บนจอ ฝึกเฉพาะสิ่งที่ไม่จับเวลา ได้แก่ อ่านโน้ต หาคีย์ ทวน ฝึกหู ความรู้คอร์ด และโหมดรอ
- **กฎเดิมที่ยังใช้:**
  - ไม่มีระบบเกม ไม่มีการเตือน
  - ระดับได้จากแบบทดสอบเท่านั้น
  - บังคับอ่านโน้ต: ไม่แสดงชื่อโน้ตโดยค่าเริ่มต้น
  - ไม่มีโน้ตหรือเนื้อร้องเพลงจริงในแอป (ลิขสิทธิ์)
  - เพลงส่วนตัวอยู่ในเครื่องเท่านั้น

## 2. สิ่งที่เปลี่ยนในระบบการฝึกจากแชทนี้

### 2.1 ตัดสินจังหวะเฉพาะเมื่อต่อสาย (v0.31.0)
- **ไฟล์:**
  - `core/input/TimingInput.kt`
  - `DailyPlan.needsCable`, `PlanContent.ladderTimed`
  - `Drill.judgesTiming`, `SkillLevel.judgesTiming`
- **แบบฝึกที่ตัดสินจังหวะ:** โหมดตามจังหวะ ชีพจร เคาะจังหวะ ทดสอบระดับที่วัดจังหวะ และสอบเกรด
  - ถ้าเปียโนต่อทางบลูทูธหรือใช้คีย์บนจอ แอปจะบอกว่า "ต่อสายก่อน (ฝึกบนคอม)"
  - ค่าความหน่วงบลูทูธที่วัดไว้เดิมไม่ใช้อีก
- **แผนวันนี้ชุดเดียวทั้งสองเครื่อง:**
  - ส่วนที่ต้องต่อสายมีป้ายบอก
  - ทำบนคอมแล้วนับในแผนหลังซิงค์
  - ถ้าเหลือแต่ส่วนที่ต้องต่อสาย หน้าวันนี้บอกให้ไปทำบนคอม
- **ฝึกหู:** `EarProgress.round(..., without)` ตัดข้อจังหวะออกจากรอบฝึกหูเมื่อไม่มีสาย

### 2.2 บอกเมื่อกดถูกตัวแต่ผิดอ็อกเทฟ (v0.31.0)
- **ที่มา:** ผลโหมดตามจังหวะที่ได้ 0% มาจากการวางมือผิดอ็อกเทฟ ไม่ใช่บั๊กจังหวะ
- **ไฟล์:** `PlayResult.octaveUp/octaveDown` และโค้ช `Advice.OctaveOff`
- **พฤติกรรม:** ถ้าเกิดซ้ำ แอปบอกให้หา C กลางก่อนวางมือ

### 2.3 ซิงค์มือถือกับคอมผ่าน GitHub (v0.31.0)
- **ที่เก็บ:** repo ส่วนตัว `coolza254-lgtm/mimikopi-data` เก็บไฟล์ `devices/<id>.json` เครื่องละไฟล์
- **การรวม:** ใช้กฎรวมเดิม `ProgressMerge` จึงไม่ทับกัน ทำซ้ำได้ผลเดิม และไม่มี conflict
- **สิ่งที่ซิงค์:**
  - บทเรียน ผลทดสอบระดับ คอร์ด หู
  - ความผิดพลาด ผลสอบเกรด
  - นาทีฝึก (แยกตามเครื่อง แสดงผลรวม)
- **สิ่งที่ไม่ซิงค์:** เพลงส่วนตัว การตั้งค่าของแต่ละเครื่อง และ token
- **เวลาซิงค์:** ตอนเปิดและปิดแอป และสำรองข้อมูลก่อนรวมทุกครั้ง
- **วิธีตั้งค่า:** `docs/SYNC.md`

### 2.4 เพลงเป้าหมาย = เพลงส่วนตัว (หลัง v0.31.0 ยังไม่ออก release)
- **ไฟล์:** `core/recall/TargetSong.kt`
- **เลือกเพลง:**
  - ใช้เพลงที่เลือกไว้ (เก็บใน setting `private.target`) ถ้าไม่ได้เลือก ใช้เพลงแรก
  - มือถือ: กดค้างที่เพลงในหน้าเพลงเพื่อตั้งเป็นเป้าหมาย
  - คอม: เลือกจากชิปบนการ์ด เพราะเพลงส่วนตัวไม่ซิงค์ แต่ละเครื่องจึงเลือกเอง
- **สถานะของแต่ละช่วง (phrase):**
  - **จำได้แล้ว:** เล่นเองจากความจำได้ ≥ 2 วัน (`LEARNED_DAYS = 2`) ในมือใดมือหนึ่ง
  - **กำลังฝึก:** มีการลองแล้ว
  - **ยังไม่เริ่ม**
- **ช่วงถัดไปที่แนะนำ:**
  1. ช่วงที่ถึงวันทวนเร็วที่สุด
  2. ถ้าไม่มี ใช้ช่วงแรกที่ยังจำไม่ได้ กับมือที่ฝึกล่าสุด (ค่าเริ่มต้นมือขวา)
- **หน้าจอ:**
  - การ์ด "เพลงเป้าหมาย" เป็นการ์ดแรกของหน้าวันนี้ ทั้งมือถือและคอม
  - ปุ่ม "เริ่มช่วงนี้" เปิดหน้าเพลงส่วนตัวที่ช่วงและมือนั้นเลย
- **ข้อจำกัด:** การ์ดนี้ใช้กลไกจำเพลงส่วนตัวเดิมทั้งหมด ซึ่งให้ผู้ใช้ประเมินตัวเอง ไม่มีโน้ตอ้างอิงมาตัดสิน

## 4. สิ่งที่ยังขาดสำหรับ piano solo เพลง H!P (ข้อเสนอให้แชทออกแบบพิจารณา)

1. **รูปแบบมือซ้าย:**
   - คอร์ดแตก, อาร์เพจจิโอ 1-5-8, เบสอ็อกเทฟ + คอร์ดจังหวะยก
   - ตอนนี้ฝึกแค่ "กดคอร์ด" ขั้นรูปแบบประกอบอยู่ในสเปกหัวข้อ 8.2 แต่ยังไม่มีแบบฝึกที่ไต่ระดับ
2. **คีย์ฝั่งแฟลตและการขึ้นคีย์:**
   - เพลง Tsunku อยู่ A♭, E♭, B♭, E บ่อย และขึ้นคีย์ท่อนท้าย
   - ระดับคอร์ดในแผนเน้น C, G, F
3. **คอร์ดสีสัน:** sus4, dim, aug, slash chord (C/E, F/G, เบสเดิน), add9
4. **ทำนองมือขวาแบบมีเสียงประสาน:** คู่ 3, คู่ 6, อ็อกเทฟ
5. **จังหวะเพลงจริง:**
   - เขบ็ต 16 บีต และโน้ตโยงข้ามจังหวะ (ซิงโคเปชัน)
   - ความเร็วจริง 100–160 bpm (ฝึกช้ากว่าได้)
6. **รวมสองมือ (ทำนอง + ประกอบ) แบบไต่ระดับ:**
   - ตอนนี้มีแค่เพลงส่วนตัวที่ประเมินตัวเอง
   - ควรมีแบบฝึกที่แอปตัดสินได้ เช่น เพลงป็อปที่แอปแต่ง (แบบส่วนเพลงป็อปในสอบเกรด) ให้เล่นได้ทุกวัน
7. **ทวนเพลงที่เล่นได้แล้ว:** "หลายเพลง" ต้องไม่ลืมเพลงเก่า สเปกหัวข้อ 2.11 บอกให้ทำในรอบถัดไป ยังไม่ได้ทำ
8. **ต่อจากโน้ตที่ซื้อ:**
   - ทางแบบ ค. ข้อ 2 ให้พิมพ์โน้ตที่ซื้อลงตัวเขียนโน้ตในแอปเพื่อให้แอปตัดสินได้ แต่ตัวเขียนโน้ตยังไม่มี
   - ต้องตัดสินว่าจะทำตัวเขียนโน้ต หรือนำเข้า MusicXML/MIDI
9. **เพลงเป้าหมายกับระดับทักษะยังไม่เชื่อมกัน:**
   - IdolGoal ประเมินความพร้อมของ 3 เพลงคงที่
   - เพลงส่วนตัวที่เลือกเป็นเป้าหมายไม่มีข้อมูลว่าต้องการทักษะอะไร

## 5. ข้อมูลจริงของผู้ใช้ (จากไฟล์สำรอง 2026-10-22)

- ฝึก 8 วันใน 12 วัน
- อยู่ด่าน 1 บท 1.6
- ระดับ: หาคีย์ระดับ 2, อ่านโน้ตระดับ 1
- **จุดอ่อน:** อ่านโน้ตบนบรรทัด
  - กุญแจซอล E4–A4 ยังอยู่กล่อง 1
  - กุญแจฟาทั้งหมดยังอยู่กล่อง 1
- **เคยลองเพลงที่ยากเกินระดับ:** Jingle Bells 100 bpm, Heroic
- **ผลโหมดตามจังหวะที่ได้ 0%:** มาจากการวางมือผิดอ็อกเทฟ แก้ด้วยคำแนะนำในข้อ 2.2
- **อุปกรณ์:**
  - เปียโน Badger C-918 ต่อ MIDI ได้ทั้ง USB และบลูทูธ (ชื่อบลูทูธ "Dight Piano MiDi")
  - คอมเป็น Windows ต่อสายเสมอ
- **วันนี้ (2026-10-22):** ผู้ใช้จะเริ่มฝึกจริงวันแรกกับแผนชุดนี้
