# ระบบ ミミコピ (PC) — มีอะไรบ้าง หลักการเรียน และเงื่อนไข

เอกสารสรุปสำหรับแก้ไขต่อ รายละเอียดเต็มและเหตุผลของแต่ละข้ออยู่ใน [`learning-system.md`](learning-system.md) (ถ้าขัดกัน ให้ยึดหัวข้อที่ใหม่กว่าในไฟล์นั้น) ตัวเลขทุกตัวด้านล่างเป็นค่าที่ตั้งเอง แก้ได้ในไฟล์ที่ระบุ

## 1. ผู้ใช้และเป้าหมาย
- ผู้ใหญ่มือใหม่คนเดียว ฝึกบนคอม Windows กับเปียโน MIDI (หรือคีย์บอร์ดคอม/เมาส์)
- เป้าหมายสุดท้าย: เล่นเพลงไอดอล (Hello! Project, AKB48) แบบ piano solo สองมือ และแกะเพลงด้วยหู (耳コピ)
- ไม่มีระบบเกม ไม่มีการเตือน ความก้าวหน้า "แบบไม่อวย": ระดับได้จากแบบทดสอบเท่านั้น

## 3. หลักการเรียน (ย่อจาก learning-system.md หัวข้อ 1)
1. ฝึกชิ้นเล็ก ช้าก่อนแล้วค่อยเร็ว (tempo ramp, วนท่อน)
2. เรียนครั้งแรกเป็นก้อน แล้วสลับหัวข้อหลังเล่นสะอาดครั้งแรก
3. อ่านโน้ตด้วยจุดอ้างอิง + ระยะห่าง ควบคู่ฝึกชื่อโน้ต
4. อ่านโน้ตใหม่ที่ง่ายทุกวัน เล่นไม่เกิน 3 รอบ (ตัวสร้างโน้ตไม่ซ้ำ)
5. จังหวะ: นับแบ่งย่อย ฝึกจังหวะแยกจากระดับเสียง
6. แยกมือเป็นวลีสั้นแล้วรวม (`E_HANDS_BUILD`) แต่มีสองมือแบบง่ายตั้งแต่ต้น
7. ฝึกสั้นทุกวัน ไม่ลงโทษวันที่ขาด
8. ทบทวนแบบเว้นระยะ (spaced repetition)

## 4. โครงหลักสูตร
- **7 แทร็กทักษะ:** `KEYS`, `READ_PITCH`, `READ_RHYTHM`, `HANDS`, `THEORY`, `EAR`, `REPERTOIRE`
- **บันได 6 ด่าน:** 1 คีย์บอร์ดและจังหวะ · 2 กุญแจซอล มือขวา · 3 กุญแจฟา มือซ้าย · 4 บรรทัดคู่ สองมือ · 5 คอร์ดและ lead sheet · 6 Piano Pop / J-Pop (เนื้อหาใน `content/`, โค้ด `core/lesson/`)
- **8 ทักษะที่มีระดับ (SkillBook):** หาคีย์ (5), อ่านโน้ต (7), จังหวะ (6), อ่านโน้ตใหม่ (7), นิ้วและสเกล (7), หู (8), คอร์ด (7), เล่นเดี่ยวสองมือ SOLO (7)
- **สาย SOLO** เปิดเมื่อถืออ่านโน้ตใหม่ระดับ 5 และคอร์ดระดับ 1 (ตารางระดับ: learning-system.md 2.12)
- **สอบเกรด** แบบ ABRSM + ส่วนป็อป: Initial–5, 6 ส่วน 150 คะแนน ผ่าน 100 / ดี 120 / ดีเยี่ยม 130 (`core/exam/Exams.kt`)

## 5. แผนรายวัน
- เลือก 10/20/30/45/60 นาที ลำดับ: วอร์มนิ้ว → ทดสอบระดับ (ถ้าถึงกำหนด) → ทวนโน้ตและคีย์ → ขั้นหลัก → ส่วนอื่นตามทักษะที่อ่อน → ทวนเพลง
- ติ๊กจากเวลาที่เล่นจริงเท่านั้น (หนึ่งรอบนับไม่เกิน 20 นาที)
- น้ำหนักเวลา: ขั้นหลัก 7, สองมือ piano solo 3.5 (เพิ่มเมื่อเป็นทักษะที่อ่อนสุด)

## 6. เงื่อนไขผ่านและกฎความก้าวหน้า
| กฎ | ค่า | ที่แก้ |
|---|---|---|
| เล่นสะอาด (clean run) | โน้ตถูก ≥ 95%, ตรงเวลา ≥ 90% ของโน้ต, หยุดนาน > 1 จังหวะไม่เกิน 1 ครั้ง | `core/playalong/` |
| เกณฑ์เวลา (≤ 80 bpm) | ด่าน 1 ±150 ms, 2 ±120, 3 ±110, 4 ±100, 5–6 ±90; เร็วกว่านั้นใช้ min(ค่านี้, 25% ของจังหวะ); โหมด strict/normal/forgiving ×0.75/1/1.3 | `core/playalong/` |
| Tempo ramp | เริ่ม 50–60% ของเป้า (≥ 40 bpm), +5 bpm (หรือ +10% ถ้า > 80) หลังสะอาด 3 รอบติด, ลดหนึ่งขั้นหลังพลาด 2 รอบติด | `core/playalong/` |
| ผ่านบทเรียน | สะอาด 3 รอบติดที่ tempo เป้า **ใน 2 วันที่ต่างกัน** + แบบฝึกประกอบผ่าน; สอบข้ามได้ครั้งเดียว | `core/lesson/` |
| ระดับทักษะ | ได้จากแบบทดสอบเท่านั้น; ไม่ผ่านระดับที่ถือ 2 ครั้งติด → ลดหนึ่ง; ลองระดับเดิมได้วันละ 2 ครั้ง; เปิดตัวช่วยระหว่างทดสอบ = ไม่นับ; ทดสอบทุก 7 วันต่อทักษะ, ระดับสูงสุดทุก 28 วัน | `core/practice/`, `core/progress/` |
| SOLO / อ่านโน้ตใหม่ | ถูก ≥ 90% และตรงจังหวะ ≥ 80% | |
| ทวนโน้ต (SRS) | กล่อง 5 ระดับ ห่าง 1/2/4/8/16 วัน; ถูกและเร็ว (≤ 3 วินาที) ขึ้นกล่อง, ผิดหรือช้ากลับกล่อง 1; ≤ 20 รายการต่อรอบ | `core/srs/` |
| ทวนเพลง | กล่องห่าง 2/4/8/16/32 วัน; เล่นทั้งเพลงสองมือสะอาดที่ tempo เป้าโดยไม่ใช้ตัวช่วย = ขึ้นกล่อง | `core/playalong/SongReview.kt` |
| ปรับความยาก | เป้าถูก 80–90%; > 92% หลายรอบ → ยากขึ้น, < 70% → ง่ายลงและแนะนำทบทวน | |
| ฝึกหู | ข้อ "รู้แล้ว" เมื่อถาม ≥ 6 ครั้งและความแข็งแรง ≥ 0.8 (ค่าเฉลี่ยถ่วง 0.3); รอบละ 12 ข้อ | `core/ear/EarCourse.kt`, `EarProgress.kt` |
| คะแนนสอบส่วนเล่น | q = 0.6×ถูก + 0.4×ตรงจังหวะ − 0.03 ต่อการหยุด (หักไม่เกิน 0.15) | `core/exam/` |
| สิ่งที่ควรแก้ | ดู 21 วันล่าสุด ต้องเกิดซ้ำหลายรอบ เช่น เร็ว/ช้าเฉลี่ยเกิน 35 ms จาก ≥ 3 รอบ | `core/progress/Mistakes.kt` |

## 7. การแสดงผลและความรู้สึก
- ตอบถูก: ✓ เขียวเด้ง + เสียงสั้นเบา; ตอบผิด: ✕ เล็ก + เสียงทุ้ม; โน้ตตก/โน้ตไหล: พลาดแล้วแถบจางเทา ไม่มี ✕ (`core/fx/AnswerSound.kt`, `ui/components/Design.kt` `AnswerFx`) ปิดเสียงได้ในตั้งค่า
- ไม่แสดงเลขบท/เลขขั้น, ไม่ใช้คำว่า "วันนี้", ป้ายผ่านสีเขียว, แถวที่ล็อกสีเทา
- 3 ภาษา: ข้อความผ่าน `tr(th, en, ja)` (`core/i18n/L10n.kt`), เนื้อหาแปลใน `core/src/main/resources/i18n/content-*.json`

## 8. ข้อมูล
- เก็บใน SQLite ในเครื่อง (`desktop/platform/`) สำรอง/คืนเป็น JSON (`core/backup/`)
- ซิงก์ระหว่างเครื่องผ่าน GitHub branch `sync-data` (ไม่ส่งเพลงส่วนตัว/โน้ตที่ซื้อ) ต้องใส่ fine-grained token ที่มีสิทธิ์ Contents read/write เฉพาะ repo นี้ (`core/sync/GitHubSync.kt`, `docs/SYNC.md`)
- อัปเดตโปรแกรมจาก release `desktop-vX.Y.Z` (`core/update/`)

## 9. แก้อะไรที่ไหน (สรุป)
- เปลี่ยนเนื้อหาบทเรียน/แบบฝึก → `content/` (+ แปลใน `content-*.json`)
- เปลี่ยนเกณฑ์/ตัวเลข → ไฟล์ใน `core/` ตามตารางข้อ 6 แล้วรัน `./gradlew -p desktop :core:test test`
- เปลี่ยนหน้าตา → `desktop/app/.../ui/` (สี/ขนาดใน `ui/theme/Tokens.kt`)
- ตัดสินใจใหม่ของผู้ใช้ → เพิ่มหัวข้อใหม่ใน `learning-system.md` พร้อมวันที่ และอัปเดตไฟล์นี้
