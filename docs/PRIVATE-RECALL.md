# เพลงส่วนตัว: ดูช่วงสั้นแล้วกลับมาเล่นเอง (v0.28.0)

## เริ่มใช้

วันนี้หรือแท็บเพลง → เพลงส่วนตัว → เพิ่มเพลงส่วนตัว
ตั้งชื่อและใส่ลิงก์ YouTube ได้ หรือเว้นลิงก์ว่างเมื่อใช้แหล่งอ้างอิงอื่นนอกแอป
เพิ่มช่วงโดยระบุเวลาเริ่ม–จบและคำใบ้ที่เขียนเอง เริ่มแค่ 1–2 ห้องหรือไม่กี่วินาที
แอปเปิดวิดีโอต้นทางด้วยแอปภายนอกที่เวลาเริ่ม ผู้ใช้หยุดเองที่เวลาจบ ไม่ดาวน์โหลดหรือควบคุมวิดีโอ

เลือกมือก่อนฝึก ผลมือขวา มือซ้าย และสองมือแยกกัน ปุ่มเริ่มลองเองซ่อนคำใบ้
เล่นด้วย MIDI หรือคีย์บนมือถือ หากไม่ได้ต่อเปียโนกับแอป ให้ระบุว่าใช้เปียโนนอกแอปด้วยตนเอง
คีย์บนจอต้องมีชุดเสียงติดตั้งตามระบบเปียโนเดิม MIDI ที่มีลำโพงใช้เสียงของตัวเองได้

หลังลอง ให้เลือกผลตามจริง:
- เล่นเองได้: ต้องยืนยันว่าไม่มีคำตอบหรือเสียงนำระหว่างรอบ และไม่มีการขอคำใบ้ในแอป
- ใช้ตัวช่วย: ดูคำใบ้ เปิดวิดีโอ หรืออาศัยคำตอบเพื่อเล่นต่อ
- ยังติด: จดว่าติดตรงไหน แล้วลองลดช่วง แยกมือ หรือฝึกคร่อมรอยต่อ

ทั้งหมดเป็น **การประเมินของผู้ใช้** ยังไม่มีโน้ตอ้างอิงให้แอปตัดสินความถูกต้องหรือสร้างเปอร์เซ็นต์
จำนวนกด MIDI/touch เป็นเพียงจำนวนเหตุการณ์ที่รับได้ ไม่ใช่โน้ตถูก และไม่ได้ใช้เป็นเวลาเล่นที่แอปคาดเดา
ไม่มีการบันทึกโน้ตที่กดเป็นไฟล์เสียง/ชีตจากหน้าฝึกนี้

## ฝึกซ้ำวันนี้กับการจำข้ามวันเป็นคนละหลักฐาน

รอบที่เล่นเองได้หลังดูต้นทางแสดงเป็นผลของรอบฝึก ไม่ยืนยันความจำก่อนเปิดดูข้ามวัน
รอบแรกของมือ/ฉบับนั้นในแต่ละวัน มีตัวเลือกให้ระบุว่าได้ลองก่อนเปิดดู/ฟังต้นทาง
แอปตรวจการเปิด YouTube ภายนอกก่อนเริ่มไม่ได้ จึงเป็นการยืนยันของผู้ใช้ ไม่ใช่การตรวจจับแอปอื่น
การเปิดคำใบ้หรือต้นทางจากแอปในระหว่างรอบจะทำให้รอบนั้นใช้ตัวช่วย

คิวทวนเริ่มวันถัดไป เมื่อทำรอบแรกก่อนดูได้ต่างวันเพิ่มขึ้นจึงเสนอห่าง 3 และ 7 วัน
เล่นซ้ำวันเดียวไม่เพิ่มจำนวนวัน ระหว่างต้องใช้ตัวช่วยหรือยังติดจะเสนอทวนเร็วขึ้น
ค่าระยะทบทวนเป็นค่าตั้งต้นของเครื่องมือ ไม่ใช่สูตรรับประกันการจำ เลือกช่วงเองได้เสมอ ไม่มีล็อกขั้นหรือการแจ้งเตือน
ผลแต่ละวลีไม่ใช้ยืนยันว่าเล่นได้ทั้งเพลง ไม่วัดนิ้ว เพดัล ไดนามิก หรือการตีความ

ออกจากหน้าหรือสลับแอปจะพักรอบ กดเริ่มใหม่ได้ หรือเลือกกลับมาลองต่อโดยนับว่าใช้ตัวช่วย
ไม่มีผลอัตโนมัติเมื่อออกกลางทาง ต้องเลือกบันทึกเองหลังเล่น มีการกดคีย์หรือระบุว่าเล่นบนเปียโนนอกแอป
ยกเลิกรอบได้โดยไม่เพิ่มผล

## การแก้และเก็บข้อมูล

- เพิ่ม/แก้เพลงและช่วงมีปุ่มบันทึก ข้อมูลที่บันทึกแล้วอยู่ในฐานข้อมูลเครื่อง ไม่มีบัญชีหรือเซิร์ฟเวอร์เพลงส่วนตัว
- ชื่อเพลง/ชื่อช่วงเปลี่ยนได้โดยไม่ล้างผลเดิม เปลี่ยนต้นทาง เวลา หรือคำใบ้จะเพิ่มฉบับอ้างอิง
  เก็บผลก่อนแก้ไว้ แต่ไม่นับแทนฉบับใหม่
- เก็บรายละเอียดผลล่าสุด 64 รอบต่อวลี และเก็บชุดวันเล่นเอง/ทวนก่อนดูระยะยาวแยกไว้ ไม่หายไปเมื่อรายละเอียดเก่าพ้นหน้าต่าง
- แสดงรายละเอียด 5 รอบล่าสุดในหน้าเพลง พร้อมมือและป้ายฉบับก่อนเมื่อมีการแก้
- ลบเพลง/ช่วงต้องยืนยัน ระบบทำ backup ภายในเครื่องก่อนนำรายการและผลออก
- ส่งออกเพลงเดียวพร้อมช่วง คำใบ้ และประวัติด้วยตัวเลือกไฟล์ Android ไปโฟลเดอร์ในเครื่อง/USB ที่เข้าถึงได้
- นำเข้า JSON ของเครื่องมือนี้เป็นสำเนาใหม่เสมอ ไม่เขียนทับเพลงเดิม จำกัดไฟล์ 4 MB และตรวจโครงสร้าง/เวลา/ลิงก์/หลักฐาน
- รองรับไม่เกิน 30 เพลงส่วนตัวและ 100 ช่วงต่อเพลงในรุ่นนี้
- การสำรองข้อมูลทั้งแอปแบบเดิมรวมเพลงส่วนตัวใน settings และสำเนาปลอดภัยยังอยู่ในเครื่อง
- คีย์เพลงส่วนตัวไม่อยู่ในรายการ LAN sync ของ ProgressMerge; ไม่มีการซิงก์เพลงส่วนตัวผ่าน LAN โดยอัตโนมัติ
- Android allowBackup=false ยังใช้ตามเดิม ไม่มีการนำข้อมูลเพลงส่วนตัวใส่โค้ด content หรือ release assets บน GitHub

## ขอบเขตรุ่นแรก

เป็นเครื่องมือแบ่งช่วง ลองเล่นเอง ประเมินตนเอง และทบทวน โดยเริ่มใช้ได้ก่อนมีโน้ตทั้งเพลง
ยังไม่มีหน้าเขียนโน้ต นำเข้า MIDI/MusicXML เพื่อตัดสินเพลงส่วนตัว ถอดเสียงอัตโนมัติ หรือบันทึก/ควบคุม YouTube
คำใบ้เป็นข้อความของผู้ใช้ ไม่ใช่คำตอบที่แอปแกะให้ อนาคตจึงค่อยเชื่อมตัวแก้โน้ตและการตรวจอัตโนมัติกับช่วงที่ยืนยันแล้ว
Heroic และแบบฝึกพื้นฐานเดิมยังอยู่ เพลงส่วนตัวไม่ถูกส่งเข้าเกณฑ์ผ่าน Heroic หรือแบบทดสอบระดับพื้นฐาน

## ตรวจที่ต้องลองกับเครื่องจริง

เพิ่มเพลง/ช่วง → เปิดต้นทาง → หยุดและกลับมา → ลองผ่าน MIDI หรือคีย์บนจอ → บันทึกผล → ปิด/เปิดแอป → ส่งออก/นำเข้า
ตรวจการสลับแอปแล้วพักรอบ การเริ่มรอบใหม่ล้างการยืนยันเดิม และการต่อ/ถอด MIDI
ภาพ native render และ unit tests ไม่ยืนยันความหน่วงหรือคุณภาพเสียงบนเปียโนจริง
