รุ่น 0.36.0: โน้ตตกแบบใหม่บนคอม โน้ตไหลผ่านเส้นเล่น ทวนเพลง อัดโน้ตที่ซื้อ และเอฟเฟกต์ตอบถูก/ผิด

- คอม โน้ตตก: แถบโน้ตเรืองแสง มือขวาสีชมพู มือซ้ายสีเหลือง บนพื้นมืด กดถูกมีแสงวาบที่เส้นเล่น กดผิดหรือไม่ตรงจังหวะแถบจะจางเป็นสีเทา (ไม่มีกากบาท) และมี % ความแม่นแบบเรียลไทม์
- คอม เล่นตามโน้ต: ระหว่างเล่นโน้ตไหลจากขวาไปซ้ายผ่านเส้นเล่นสีชมพูที่อยู่กับที่ มีปุ่ม "ชื่อโน้ต" เปิด/ปิด และปุ่ม "‹ ย้อนห้อง" (หรือกดลูกศรซ้าย) กับ "↻ เล่นห้องนี้ใหม่" เล่นใหม่ได้โดยไม่ต้องออก
- ตอบถูก: ✓ สีเขียวเด้งขึ้นพร้อมเสียง "ติ๊ง" เบา ๆ · ตอบผิด: ✕ เล็กพร้อมเสียงทุ้มนุ่ม · จบเพลงสะอาด: ✓ ใหญ่และเสียง ド ミ ソ ใช้กับอ่านโน้ต คอร์ด ฝึกหู และเล่นตามโน้ต ปิดเสียงได้ที่ตั้งค่า → เสียงตอบถูก/ผิด
- ทวนเพลงที่ผ่านแล้ว: เพลงในคลังที่ผ่านแล้วกลับมาให้ทวนห่างขึ้นเรื่อย ๆ (2, 4, 8, 16, 32 วัน) ส่วน "เล่นเพลง" ในแผนเปิดเพลงที่ถึงกำหนดก่อน
- คอม: หน้าเพลง → "โน้ตที่ซื้อ" อัดโน้ต piano solo จากเปียโนทีละมือทีละช่วงตามเมโทรนอม แอปจัดลงจังหวะ แตะโน้ตผิดแล้วกดคีย์ที่ถูกเพื่อแก้ แล้วฝึกแบบเล่นตามได้ เก็บในคอมเครื่องนี้เท่านั้น
- คอม: ไอคอนโปรแกรมเป็นโลโก้ของแอป (ถ้ายังเห็นไอคอนเก่า ลบทางลัดบนเดสก์ท็อปแล้วสร้างใหม่)
- แผนวันนี้ไม่แสดงเลขบทและเลขขั้นแล้ว

ข้อมูลเดิมอยู่ครบ ควรอัปเดตทั้งมือถือและคอม ยังไม่ได้ตรวจบนเครื่องจริง
