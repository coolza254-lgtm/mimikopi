รุ่น 0.17.0: ミミコピ สำหรับ Windows (ช่วงแรก)
- โปรแกรมติดตั้งสำหรับ Windows: ไฟล์ mimikopi-windows-v0.17.0.msi ในหน้า release เดียวกับแอพมือถือ
- ช่วงแรกมี ฝึกฟัง (บันได 36 ขั้น) และ ฝึกท่อน (จดโน้ตด้วยการเล่น ฝึกทีละวลี) หน้าตาขาวดำแบบเดียวกับมือถือ มีโหมดมืด สว่าง และตามเครื่อง
- ต่อคีย์บอร์ด MIDI ทางสาย USB (บลูทูธยังไม่รองรับในรุ่น Windows)
- เสียงเปียโน: เริ่มด้วยเสียงพื้นฐานของ Java และดาวน์โหลดเสียงเปียโนแกรนด์ชุดเดียวกับมือถือได้ในตั้งค่า (ราว 79 MB)
- ย้ายความคืบหน้าและท่อนที่จดไว้จากมือถือ: ส่งออกไฟล์สำรองในมือถือ แล้วนำเข้าในตั้งค่าของโปรแกรม (ย้ายกลับได้เหมือนกัน)
- อ่านโน้ตและเพลงจะตามมาในช่วงถัดไป
- แอพมือถือ: ไม่มีอะไรเปลี่ยน
- โปรแกรมไม่ได้เซ็นชื่อดิจิทัล ตอนติดตั้ง Windows อาจเตือน "Windows protected your PC" ให้กด More info → Run anyway
