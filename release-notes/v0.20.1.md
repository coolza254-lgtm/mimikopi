รุ่น 0.20.1: เก็บรายละเอียดให้ครบ (มือถือและ Windows)
- รุ่น Windows มีหน้าเมโทรนอมแล้ว (ตั้งค่า → เปิดเมโทรนอม): ความเร็ว จังหวะ เน้นจังหวะแรก เสียงย่อย และความดัง
- รุ่น Windows ตั้งความเข้มงวดของจังหวะได้แล้ว (เข้ม / ปกติ / ผ่อน) ค่าเดียวกับในมือถือ ย้ายกับไฟล์สำรองได้
- รุ่น Windows ถามตัวตนเปียโนเหมือนในมือถือ ถ้าเปียโนตอบ จะขึ้นติ๊กเขียวทันทีที่ต่อ และรู้เมื่อปิดเครื่อง
- หน้าเกี่ยวกับแอพในมือถือ: อัปเดตรายการสิ่งที่ยังไม่มีให้ตรงกับตอนนี้ และเครดิตฟอนต์ให้ถูกต้อง
- เอาโค้ดและเนื้อหาของบันไดฝึกฟังแบบเก่าออกทั้งหมด (แอพเล็กลงเล็กน้อย ไม่มีอะไรเปลี่ยนในการใช้งาน)
