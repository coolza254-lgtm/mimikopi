# หน้าฝึกหู

ผู้ใช้เลือก **B · ลำดับชัด** (`steps.html`) เมื่อ 2026-10-21 และนำไปทำในหน้าฝึกจริงรุ่น 0.26.4 แล้ว

เปิด `index.html` เพื่อเปรียบเทียบทั้งสามแนวทาง แต่ละแบบมีสวิตช์มือถือ/MIDI และตัวอย่างลำดับเสียง
ปุ่มจำลองการตอบ MIDI ในหน้าเว็บเป็นเครื่องมือดูแบบ หน้า Android รับคำตอบจาก MIDI จริงผ่าน InputHub
เสียงสังเคราะห์ใน HTML ใช้สาธิตการเว้นจังหวะเท่านั้น เสียงแอปจริงมาจาก piano engine เดิม

ภาพหน้าจอ Android ที่ตรวจด้วย Compose อยู่ใน `../../docs/images/ear-b-*-v0.26.4.png`
รายละเอียดการตรวจและสิ่งที่ต้องลองบนโทรศัพท์อยู่ใน `../../docs/MOBILE-VALIDATION.md`
