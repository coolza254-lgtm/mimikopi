รุ่น 0.2.0 (M2): อัปเดตในแอพ + สำรองข้อมูล
- เมนูใหม่ "ตั้งค่า อัปเดต และสำรองข้อมูล"
- ปุ่ม "ตรวจหาอัปเดต": ดาวน์โหลดรุ่นใหม่ ตรวจ SHA-256 และกุญแจเซ็นก่อนติดตั้ง ระบบจะถามยืนยันทุกครั้ง
- ก่อนอัปเดต แอพสำรองข้อมูลไว้ในเครื่องอัตโนมัติ และเสนอให้บันทึกไฟล์สำรองไว้ที่อื่นด้วย
- บันทึก/กู้คืนข้อมูลทั้งหมดเป็นไฟล์ JSON
- หน้า "ข้อมูลเครื่อง" แสดงเวลาตรวจอัปเดตล่าสุด
