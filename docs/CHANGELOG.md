- นำเพลงอื่นทั้ง 30 ไฟล์ออกจากคลัง เหลือ Heroic Polonaise เพลงเดียว สองฉบับของท่อนหลักห้อง 17–24
- เพิ่มแผน 30 เป้าหมายจากแยกมือทีละสองห้อง → รวมมือ → เชื่อมรอยต่อ → รวมท่อน → เพิ่มความเร็ว จาก C ไป A♭
- ปุ่มเริ่มตั้งค่าให้ตรงเป้าหมาย ติดตามโน้ต จังหวะ ความเร็ว วันที่ทำได้ และห้องที่ต้องทวนแยกตามช่วง/มือ
- เกณฑ์อ่านแยกจากเกณฑ์จังหวะ รอบหยุดกลางทาง ตัวช่วย และเปิดเล่นโดยไม่กดไม่ทำให้ผ่านเป้าหมาย
- หน้า Today/เป้าหมาย/เพลงเน้น Heroic แทนเพลงไอดอล เก็บประวัติเดิมและเพิ่มหลักฐานใหม่ใน backup/sync เดิม
- บทเรียนที่ใช้เพลงอื่นเปลี่ยนเป็นแบบฝึกพื้นฐาน หน้าแบบสอบหลายเพลงเหลือทางเข้าวัดพื้นฐานและประวัติสอบ
- ผลของแผนนี้เป็นของท่อนหลักฉบับฝึกเท่านั้น ไม่รับรองว่าเล่นต้นฉบับเต็มได้

# การเปลี่ยนแปลง

## 0.26.8 — Heroic Polonaise และการตรวจไฟล์เพลง
- เพิ่ม Chopin Heroic Polonaise Op.53 ท่อนหลัก 8 ห้อง สองฉบับ: ง่ายใน C และฉบับฝึกคอร์ดใน A♭
- ขยายชุดคลาสสิกเป็น 13 ขั้น พร้อมสิ่งที่ย่อและเครดิตข้อมูลจาก Fryderyk Chopin Institute (CC BY 4.0)
- แก้การทดสอบแปลงโน้ตให้เทียบเสียง จังหวะ ความยาว และมือ โดยไม่เทียบรหัสเฉพาะที่เปลี่ยนได้เมื่อจัดตัวหยุดใหม่
- ระบุ content เป็น input ของการทดสอบ ป้องกันผลเก่าจากแคชเมื่อเพิ่มหรือแก้เพลง

## 0.26.7 — คลาสสิกจากง่ายไปยาก พร้อม Chopin
- เพิ่มเพลงฝึก 6 ไฟล์: Ode to Joy ห้าโน้ต, Brahms’ Lullaby, Canon in D, Chopin Prelude in E minor สองฉบับ และ Mozart Sonata K.545 ท่อนเปิด
- หน้ารวมคลาสสิก 11 ขั้นพร้อมสิ่งที่ควรฝึกและมือที่แนะนำ เพลงทั้งหมดเปิดได้ ไม่ผูกกับการเลื่อนระดับทักษะ
- Chopin ฉบับเบสง่ายและคอร์ดเคลื่อนใช้ทำนองเดียวกันเพื่อค่อยเพิ่มความยากของมือซ้าย
- ระบุท่อนย่อ เครดิต แหล่งโน้ต การดัดแปลง และใบอนุญาตรายเพลง เปิดดูได้ในแอป
- คงรายชื่อทุกเพลงและรายการเฉพาะบทเรียนเดิม พร้อมประวัติฝึกจาก id เดิม

## 0.26.5 — ฝึกอ่านโน้ตบนมือถือและ MIDI
- เพิ่มหน้ารวมอ่านทีละตัว/ทำนอง และแบบฝึกอ่านชื่อที่เลือกกุญแจ ช่วงเสียง เครื่องหมาย และจำนวนข้อได้
- มือถือใช้ปุ่มชื่อพร้อมอ็อกเทฟสำหรับอ่านทีละตัว ต่อ MIDI แล้วใช้คีย์จริงโดยไม่มีปุ่มชื่อบนจอ
- ตอบผิดหยุดให้อ่านเฉลย กดไปต่อหรือแก้ด้วย MIDI ได้ เก็บคะแนนครั้งแรกแยกจากข้อทวน
- แก้คิวข้อทวนที่เคยทำให้โจทย์ปกติซึ่งมีโน้ตซ้ำกับข้อที่พลาดถูกข้ามการนับผลครั้งแรก
- หน้าตั้งค่าทำนองเน้นเริ่มฝึก วิธีฝึก และความเร็ว เริ่มการฝึกอิสระแบบ WAIT; เกณฑ์บทเรียน/ทดสอบ/สอบไม่เปลี่ยน
- โหมด WAIT เก็บความแม่น แต่ไม่บันทึกความแม่นจังหวะหรือ clean run ที่ไม่ได้วัด
- คีย์บนมือถือเปลี่ยนอ็อกเทฟได้ มีสองช่วงกดพร้อมกันสำหรับสองมือ และปล่อยโน้ตเมื่อ input ถูกยกเลิก
- ปุ่มหยุดเข้าถึงได้เมื่อขยายตัวอักษร; ผลอ่านทีละตัวบอกเวลาตอบและโน้ตที่ควรฝึกต่อ

## 0.26.4 — ฝึกหู: ฟัง พัก ตอบ เฉลย
- ใช้หน้าฝึกแบบ B ที่ผู้ใช้เลือก พร้อมสถานะเสียงชัดเจนและ layout แนวนอน/ธีมมืด
- เว้นหลังคอร์ดนำ 900 ms; ปิดรับคำตอบระหว่างโจทย์และการฟังซ้ำ
- ปิดเสียงตอบจากทุก input โดยไม่เปลี่ยนค่าการเล่นเสียงของผู้ใช้ และคืนค่าตามเดิมเมื่อออกจากหน้า
- เฉลยรอปล่อยคีย์/แป้นเหยียบต่อเนื่อง 450 ms และห่างจากคำตอบอย่างน้อย 500 ms; ฟังซ้ำและข้อใหม่รอปล่อยคีย์เช่นกัน
- ต่อ MIDI แล้วซ่อนปุ่มตอบบนจอ ใช้โน้ตจริงสำหรับโจทย์โน้ต/เบส/ทำนอง ใช้คีย์ใดก็ได้สำหรับจังหวะ และแสดงคีย์เลือกคำตอบสำหรับคำถามเชิงทฤษฎี
- กด C หลังเฉลยจบเพื่อไปต่อได้ โดยแอปรอปล่อยคีย์ก่อนเสียงข้อใหม่
- ยกเลิกงานเสียงที่ค้างเมื่อพัก/ออกจากหน้าฝึก และแก้ race ในตัวส่งโน้ตที่อาจเริ่มเสียงเก่าหลังสั่งหยุดแล้ว
- เนื้อหาโจทย์และเกณฑ์คะแนนเดิมไม่เปลี่ยน

## 0.26.3 — โน้ตไหลแนวนอนเต็มจอ
- พื้นโน้ตและคีย์ใช้พื้นที่เต็มจอขณะเล่น/ฟังในแนวนอน ย้ายปุ่มหยุดและสวิตช์ชื่อเป็นแถบซ้อนด้านบน
- ซ่อน system bars ชั่วคราว วาดพื้นถึงขอบรอยบาก โดยปุ่มควบคุมหลบรอยบาก
- กดหยุด/ย้อนกลับหรือหมุนแนวตั้งจะคืนรูปแบบปกติ

## 0.26.2 — โน้ตไหลและเอฟเฟกต์ผลการกด
- เปลี่ยนพื้นที่โน้ตไหลเป็นพื้นเข้ม แถบโน้ตสีน้ำเงินสำหรับมือซ้ายและสีเขียวสำหรับมือขวา พร้อมคีย์เปียโนมีมิติ
- เปิด/ปิดชื่อบนคีย์ขาวและคีย์ดำได้ระหว่างเล่นและจำค่าที่เลือก โดยไม่เปลี่ยน tempo หรือเกณฑ์ตัดสิน
- แสดงประกายเมื่อกดถูก คำเตือนเร็ว/ช้า กากบาทผิดคีย์ และเครื่องหมายโน้ตที่พลาด จากผล judge จริง
- เรขาคณิตการวาดและรับสัมผัสตรงกัน และไม่รับคีย์เมื่อแตะหรือลากออกนอกขอบ

## 0.26.1 — มือถือ: ฝึกแล้วรู้ว่าควรแก้อะไรต่อ
- หน้า Today เลือกเวลาได้ใกล้ปุ่มเริ่ม ดูแผนละเอียดเมื่อต้องการ และเห็นเวลาที่เล่นจริงถึงวินาที
- แยกการทำครบแผนออกจากการผ่านระดับทักษะ ป้องกันการตีความความคืบหน้าเกินผลจริง
- หน้าผลการอ่านโน้ตแสดงเต็มพื้นที่ มีปุ่มเริ่มฝึกแก้จุดผิดทันที พร้อมฝึกช้าลงเฉพาะบาร์หรือมือ
- แก้แผนรายวันที่จัดเวลาไม่ครบ/เกินในบางสถานะ และจัดแผนที่บันทึกผิดใหม่โดยเก็บประวัติฝึกไว้
- ถ้าทักษะนิ้วและสเกลอ่อนที่สุด เพิ่มเวลาในช่วงฝึกหลักแทนช่วงวอร์มนิ้วที่มีเวลาคงที่
- โหมดตามจังหวะที่ปล่อยจนจบโดยไม่กดโน้ตเลยไม่นับเป็นเวลาซ้อม การกดผิดยังนับเป็นความพยายามฝึก
- แก้วัดความหน่วงที่เคยนับคอร์ด/การกดซ้ำเป็นหลายจังหวะ และแยกผลตาม input source
- พักการสร้าง PC จนผู้ใช้พอใจกับมือถือ
