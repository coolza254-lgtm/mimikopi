รุ่น 0.28.0: เพลงส่วนตัว — ฝึกจากคลิปจนลองเล่นเองได้

- วันนี้/แท็บเพลง → เพลงส่วนตัว เพิ่มชื่อ ลิงก์วิดีโอ ช่วงเวลา และคำใบ้ที่คุณเขียนเอง
- หยุดวิดีโอแล้วลองด้วย MIDI หรือคีย์บนมือถือ บันทึกว่าเล่นเอง ใช้ตัวช่วย หรือยังติด พร้อมจดจุดที่ควรซ่อม
- แยกผลหลังฝึกจากรอบแรกก่อนเปิดดูวันอื่น เสนอทวน 1, 3, 7 วันตามผล ไม่เพิ่มหลักฐานข้ามวันจากการเล่นวนวันเดียว
- คำใบ้ซ่อนระหว่างลอง เปิดแล้วนับว่าใช้ตัวช่วย สลับแอปแล้วพักรอบ และเริ่มรอบใหม่ได้
- ข้อมูลเพลงส่วนตัวอยู่ในเครื่อง ส่งออก JSON พร้อมประวัติไปโฟลเดอร์/USB และนำกลับเป็นสำเนาใหม่ได้
- Heroic และแบบฝึกพื้นฐานเดิมยังอยู่ ข้อมูลเพลงส่วนตัวไม่อยู่ใน APK, GitHub หรือรายการ LAN sync

ผลเพลงส่วนตัวเป็นการประเมินของคุณ แอปยังไม่ได้ตรวจว่าโน้ต/จังหวะตรงกับเพลงต้นฉบับ
รุ่นนี้ยังไม่มีหน้าเขียนโน้ต ถอดเสียงอัตโนมัติ นำเข้า MIDI/MusicXML สำหรับตรวจเพลงส่วนตัว หรือควบคุม YouTube
ลิงก์ต้นทางเปิดในแอปภายนอกที่เวลาเริ่ม คุณหยุดเองเมื่อถึงเวลาจบ
