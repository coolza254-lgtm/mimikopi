# มือถือก่อน PC

ผู้ใช้ยืนยัน 20 ต.ค. 2026 ให้ทำมือถือจนพอใจก่อนค่อยทำ PC เป้าหมายหลักคือ UX/UI ที่ใช้ง่าย
และการฝึกที่ practical เห็นผลจากการเล่นจริง งาน PC ที่เริ่มไว้ถูกพักนอก checkout ที่
`/workspace/shared/pc-deferred` และไม่ได้รวมใน build

## เส้นทางหลักที่ต้องทำให้ดี
เปิดแอป → รู้ว่าฝึกอะไรและเพราะอะไร → เริ่มเล่น → รู้ข้อผิดพลาดที่ควรแก้ก่อน → เริ่มฝึกแก้ทันที
คงภาษาไทย รูปแบบขาวดำ/สองธีม และชื่อโน้ตตามที่ผู้ใช้เลือก ไม่เพิ่มแต้ม รางวัล streak หรือการแจ้งเตือน

## รอบนี้
- เลือกเวลาที่หน้า Today ด้านบน แสดงกิจกรรมถัดไปเป็นหลัก เปิดดูแผนทั้งหมดได้
- แสดงเวลาจริงถึงวินาที และบอกชัดว่าทำครบส่วนของแผนไม่ได้แปลว่าผ่านระดับทักษะ
- แผนใช้เวลารวมตามที่เลือกเสมอ แม้กิจกรรมยังเปิดไม่ครบ; แผนเก่าที่ผลรวมผิดจะจัดใหม่
  โดยไม่ลบเวลาซ้อมหรือผลทดสอบ
- ทักษะนิ้วและสเกลที่อ่อนจะได้เวลาเพิ่มในช่วงฝึกหลัก ไม่สูญเสียการเพิ่มเวลาเพราะวอร์มนิ้วเป็นช่วงคงที่
- หน้าผลอ่านโน้ตใช้เต็มพื้นที่ เน้นคำแนะนำเดียวและปุ่มเริ่มฝึกแก้ทันที
- ฝึกแก้เฉพาะบาร์/มือช้าลง ไม่ให้ tempo ramp เปลี่ยนค่าที่ปุ่มสัญญาไว้ มีทางกลับไปลองทั้งเพลง
  ส่วนแบบทดสอบและการสอบคงเกณฑ์เดิม
- วัด latency ต้องใช้คนละคลิกอย่างน้อย 10 ครั้ง คอร์ด/กดซ้ำไม่เพิ่มจำนวนหลักฐาน
  ไม่ผสม timestamps จาก MIDI กับ touch ในผลเดียว

## ยังต้องใช้ผลจากผู้ใช้ก่อนเรียกมือถือว่าเสร็จ
- เปิดแล้วเริ่มฝึกได้ง่ายบนขนาดจอและขนาดตัวหนังสือที่ใช้จริง
- คำแนะนำหลังเล่นชี้จุดผิดที่พบจริง และฝึกแก้แล้วกลับมาเล่นท่อนเดิมได้ดีขึ้น
- ความตรงของเวลา/คุณภาพเสียง/USB MIDI/CC64 และการต่อหลุดบน Badger C-918
- ทดสอบการใช้งานทุกวัน เพื่อปรับความยาวและลำดับฝึกตามผล ไม่รับรองพัฒนาการจากเวลาเปิดแอป

ผล emulator ยืนยัน navigation และการแสดงผลได้ แต่ยืนยันความหน่วงจริงหรือประสิทธิผลระยะยาวไม่ได้
ไม่เริ่มพัฒนา PC ต่อจนผู้ใช้พอใจเวอร์ชันมือถือ
