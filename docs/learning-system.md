# ระบบการเรียน (Learning System Spec) — ミミコピ (Mimi Kopi)

ไฟล์นี้คือรายละเอียดของระบบการเรียนทั้งหมดของแอพ ใช้คู่กับ `prompt.md`
- ถ้าเนื้อหาขัดกับหัวข้อ 5.1, 5.2, 5.5, 5.6 ใน `prompt.md` ให้ยึดไฟล์นี้
- เขียนเป็นภาษาไทยเพราะผู้ใช้เป็นคนไทยและจะอ่านเอง ชื่อฟิลด์ โค้ด และศัพท์เทคนิคใช้ภาษาอังกฤษ
- Claude Code ต้องเขียนเนื้อหาบทเรียนจริง (ภาษาไทย) จากพิมพ์เขียวนี้ บทที่ 1.1 ในหัวข้อ 10 เขียนเต็มไว้เป็นมาตรฐานคุณภาพที่ต้องรักษา
- ตัวเลขทั้งหมดเป็น "ค่าเริ่มต้นที่ปรับได้" ที่ผมตั้งเองจากหลักการออกแบบ ไม่ใช่ค่าจากงานวิจัย ให้เก็บใน config ไม่ฝังในโค้ด

## 0. ผู้เรียนและเป้าหมาย

- ผู้เรียน: ผู้ใหญ่ชาวไทย เริ่มจากศูนย์ ไม่มีพื้นฐานดนตรี ฝึกวันละประมาณ 30 นาที
- เล่นบนเปียโนจริง (Badger C-918 ผ่าน MIDI) และบนคีย์บอร์ดหน้าจอ วางมือถือบนที่วางโน้ตเป็นหลัก
- **เป้าหมายปลายทาง: เล่นเพลงส่วนใหญ่ของ Hello! Project และ AKB48 ได้** และอ่านโน้ตเปียโนได้
- นัยของเป้าหมายนี้: "เพลงส่วนใหญ่" มีเป็นร้อยๆ เพลง และโน้ตเปียโนทางการมีไม่ครบทุกเพลง ดังนั้นแอพต้องสอนทักษะแบบ **สร้างเพลงเองได้** (อ่าน lead sheet, เล่นคอร์ดประกอบ, ถอดเพลงจากหู) ไม่ใช่ให้ท่องจำโน้ตทีละเพลง รายละเอียดอยู่ในหัวข้อ 9

## 1. หลักการออกแบบ พร้อมระดับหลักฐาน

ผมค้นข้อมูลจากครูเปียโน บทความ และงานวิจัยบางชิ้น ต้องบอกตรงๆ ว่า **หลักฐานส่วนใหญ่เป็นประสบการณ์ของครู ไม่ใช่การทดลองควบคุมที่แข็งแรง** และงานวิจัยหลายชิ้นทำกับเด็กหรือนักดนตรีที่เล่นได้แล้ว ไม่ใช่ผู้ใหญ่มือใหม่ จึงให้ถือเป็นค่าเริ่มต้นที่ต้องวัดผลกับผู้ใช้จริง (ดูหัวข้อ 12)

| 5 | จังหวะ: นับแบ่งย่อย เคาะเท้า พูดจังหวะก่อนเล่น | บทความครูเพอร์คัชชัน/ครูเปียโน | ฝึกจังหวะแยกโดยไม่มีระดับเสียง นับเสียงดัง |

| 10 | ทบทวนแบบเว้นระยะสำหรับชื่อโน้ต ฯลฯ | เทคนิคทั่วไป (Leitner) ไม่ใช่งานเฉพาะเปียโน | กล่อง 5 ระดับ ดูหัวข้อ 6 |

## 2. โมเดลทักษะและข้อมูลที่ต้องเก็บ

### 2.1 แทร็กทักษะ (7 แทร็ก)
`KEYS` ตำแหน่งคีย์บอร์ด, `READ_PITCH` อ่านระดับเสียง, `READ_RHYTHM` อ่านจังหวะ, `HANDS` สองมือและเทคนิค, `THEORY` คีย์/คอร์ด, `EAR` หู, `REPERTOIRE` เพลง

ทุกบทเรียนและแบบฝึกหัดสังกัดอย่างน้อยหนึ่งแทร็ก แอพแสดงระดับของแต่ละแทร็กแยกกัน (เช่น อ่านเสียงได้ดีกว่าอ่านจังหวะ) และเลือกแบบฝึกหัดที่เสริมแทร็กที่อ่อนที่สุด

### 2.2 ข้อมูลที่ต้องบันทึกทุกครั้งที่ทำแบบฝึกหัด
```
attempt { exercise_id, params, started_at, hand, tempo_bpm,
  events[ { expected_pitch, actual_pitch, expected_onset_ms,
            actual_onset_ms, offset_ms, velocity } ],
  result{ note_accuracy, timing_within_tol, stumbles, clean } }
item_stats { item_id (เช่น "note:G4:treble"), box 1-5, due_at,
  last_results[], median_response_ms }
```

### 2.3 การตั้งค่าตอนเริ่มใช้ (สำคัญต่อความแม่นยำ)
1. **Latency calibration**: ให้ผู้ใช้กดตามเสียงคลิก 16 ครั้ง แอพคำนวณค่าหน่วงเฉลี่ยของ MIDI/ลำโพง แล้วหักออกในการตัดสินจังหวะ (Bluetooth MIDI มักหน่วงกว่า USB ให้เก็บค่าแยกตามชนิดการเชื่อมต่อ)
2. **Octave offset calibration**: ให้กด Middle C หนึ่งครั้ง เพราะบางเครื่องส่งเลขโน้ตเลื่อนอ็อกเทฟ และคีย์บอร์ดบางรุ่นมีไม่ครบ 88 คีย์
3. **ชื่อโน้ต**: สลับแสดง C D E / โด เร มี ได้ ค่าเริ่มต้นแสดงทั้งสองแบบคู่กันในบทแรกๆ
4. **ทดสอบความไวต่อแรงกด**: ให้กดเบาและแรง ถ้าเครื่องส่ง velocity คงที่ ให้ปิดทุกอย่างที่ต้องใช้ dynamics (บทเรียน dynamics กลายเป็นแบบ "ฟังและเลียนแบบ" ไม่ตัดสินจากแรงกด และห้ามใช้ dynamics เป็นเงื่อนไขผ่านด่าน)

### 2.4 การตัดสินใจของผู้ใช้ที่มีผลต่อหลักสูตร (ล่าสุด 2026-10-11 ชนะข้อความอื่นถ้าขัดกัน)
- **บังคับอ่านโน้ตตั้งแต่วันแรก:** คีย์บอร์ดบนจอไม่แสดงชื่อตัวโน้ตโดยค่าเริ่มต้น มีปุ่มช่วยดูชื่อได้ แต่นับจำนวนครั้ง และผลที่ใช้ตัวช่วยไม่นับเป็นผ่านเต็ม
- **ไม่มีระบบเกม:** ไม่มีดาว สติกเกอร์ ตัวละคร เน้นข้อมูลที่ช่วยฝึกจริง (ความแม่นยำ จังหวะเร็ว/ช้า รายการที่ต้องทวน เทียบรายสัปดาห์) ภาพลักษณ์ "สมุดดนตรีน่ารัก" เป็นเพียงลุคภาพ
- **ตรวจ velocity อัตโนมัติ:** ผู้ใช้เชื่อว่า Badger C-918 ไม่ไวต่อแรงกด (ยังไม่ยืนยัน) แอพทดสอบหลังต่อ MIDI (หัวข้อ 2.3 ข้อ 4) ถ้า velocity คงที่ ซ่อนแบบฝึกน้ำหนักเสียงทั้งหมด เทคนิคที่ฝึกมี: ตำแหน่งห้านิ้ว สเกล อาร์เพจโจ การเปลี่ยนคอร์ดเร็วและเรียบ ความเท่ากันของจังหวะ สองมือต่างหน้าที่ legato ซัสเทน (ถ้ามี CC64)
- **เวลา:** 30 นาทีต่อวันเป็นค่าตั้งต้น แต่อาจฝึกมากกว่านั้น จึงมีเวอร์ชัน 15/30/45/60 นาที
- **ช่วงเล่นเอง:** ทุกเซสชันมีช่วงเล่นเองหรือแกะเพลงตามใจ ไม่มีคะแนน
- **ระบบเตือน:** ผู้ใช้ไม่ต้องการในตอนนี้ (ทำทีหลังเป็นตัวเลือกปิดไว้ก่อน)

## 2.5 ระบบบันไดฝึก (ผู้ใช้ขอเมื่อ 2026-10-14 ชนะหัวข้อ 3, การจัดเป็นบทในหัวข้อ 4, 6.4 และ 11.1 ถ้าขัดกัน)

ผู้ใช้ต้องการให้ "เปิดแอพ ต่อเปียโน แล้วเรียนไปเรื่อยๆ โดยไม่ต้องคิดมาก" ฝึกซ้ำให้เชี่ยวชาญจริง ทักษะไม่แยกกระจาย และยังวัดผลจริงจัง ฝึกฟังให้ค่อยเป็นค่อยไป

- **บันไดทางเดียว:** บทเรียน 50 บทของด่าน 1–6 (หัวข้อ 4) ถูกแตกเป็น **ขั้นเล็ก 138 ขั้น** หนึ่งขั้น = แบบฝึกเดียว (แบบรอหรือตามจังหวะ, หาคีย์, อ่านโน้ต, คอร์ด, เพลง ฯลฯ) เรียงต่อกันตามลำดับบทเดิม แต่ละขั้นมีคำอธิบายสั้น 1–2 ข้อ และกด "อ่านละเอียด" ได้ เนื้อหาเดิมทั้งหมดยังอยู่ (คำอธิบาย เพลง ตัวสร้างโจทย์)
- **เกณฑ์ผ่านทุกขั้นวัดจากการเล่นจริง:** ใช้เกณฑ์ของแบบฝึกนั้นจากบทเดิม (ความแม่น เวลา เล่นสะอาด) แบบฝึกโหมดรอซึ่งไม่จับเวลา นับรอบที่ "ถูกตั้งแต่ครั้งแรก ≥ 90%" เป็นรอบสะอาด
- **ผ่านวันนี้ + ยืนยันวันถัดไป:** ผ่านเกณฑ์ในวันหนึ่ง ขั้นถัดไปเปิดทันที วันถัดไปช่วงแรกของการฝึกคือ "ยืนยัน" (ทำขั้นนั้นอีกครั้งให้ผ่านเกณฑ์) ถ้าวันที่ลองยืนยันจบลงโดยยังไม่ผ่าน ขั้นนั้นกลับไปเป็นขั้นที่ต้องฝึกใหม่ (ไม่มีการข้าม) ขั้นเพลงที่ใช้กฎผ่านเพลง (สะอาด 3 รอบติดใน 2 วันคนละวัน) และขั้นเพลงในคลังนับผ่านในวันเดียว
- **เซสชันรายวันเรียงให้อัตโนมัติ (ไม่จำกัดเวลา):** 1) ยืนยันขั้นที่ผ่านเมื่อวาน (สูงสุด 3) 2) ทวนโน้ตและคีย์ตาม spaced repetition 3) ฝึกซ้ำขั้นเก่าที่ผ่านแล้วหนึ่งขั้น (เลือกตามวันที่) 4) ขั้นใหม่ของวันนี้ ฝึกซ้ำจนผ่าน และฝึกขั้นต่อไปได้ถ้ายังไหว 5) ฝึกฟังหนึ่งขั้น 6) วัดผลเมื่อครบ 2 สัปดาห์ หน้า "วันนี้" มีปุ่มเดียวที่พาไปส่วนถัดไปเสมอ
- **บันไดฝึกฟัง 30 ขั้น แยกจากบันไดหลัก:** แทนการสุ่มหลายระดับของหัวข้อ 11.1 แต่ละขั้นแคบมาก เช่น สูง/ต่ำที่ห่างหนึ่งอ็อกเทฟ → ห่างมาก → ปานกลาง → น้อย → ติดกัน; ระยะเริ่มจากแยกคู่ 8 กับคู่ 5 แล้วเพิ่มทีละระยะ (คู่ 3, คู่ 2, คู่ 4 …); ปุ่มคำตอบมีเฉพาะตัวเลือกของขั้นนั้น ผ่านเมื่อถูก ≥ 90% (ขั้นโปรเกรสชันขึ้นไป ≥ 85%, ขั้นสุดท้าย ≥ 80%) จาก 20 ข้อ และยืนยันวันถัดไปเหมือนบันไดหลัก ขั้นฟังแต่ละขั้นเปิดหลังถึงขั้นบนบันไดหลักที่สอนเรื่องที่เกี่ยวข้อง
- **ความก้าวหน้าเดิมไม่หาย:** บันทึกของบทเดิมถูกแปลงเป็นบันทึกของขั้นที่มาจากแบบฝึกนั้น (วันที่แบบฝึกนั้นผ่านเกณฑ์ บวกวันที่บทผ่าน) บันทึกเดิมเก็บไว้ใน settings "lesson.records.v1"
- การวัดผลทุก 2 สัปดาห์ (หัวข้อ 12.1) ไม่เปลี่ยน และใส่ในรายการของวันนั้นอัตโนมัติ

## 2.6 แผนวันนี้ ระดับทักษะ และเปียโนอิสระ (ผู้ใช้ขอเมื่อ 2026-10-16 ชนะหัวข้อ 2.5 เรื่องเซสชันรายวัน และหัวข้อ 12.1 ถ้าขัดกัน)

ผู้ใช้ขอให้ "ออกแบบการฝึกใหม่ให้ได้ผลจริง" อยากมาฝึกทุกวัน (ไม่มีระบบเกม ไม่มีการเตือน) ติดตามความก้าวหน้าเป็นทักษะแต่ละด้าน "แบบไม่อวย" หน้าตาเรียบแบบแอพของ Apple เพิ่มเปียโนอิสระที่ใช้เสียงของแอพ และตัดโหมดจดเพลงออก

- **แท็บ 4 แท็บ:** วันนี้ · ทักษะ · เปียโน · เพลง บันไดหลัก (ขั้นหลัก) ฝึกฟัง และคอร์ด เป็นหน้าที่เปิดจากแผนวันนี้หรือจากหน้าทักษะ (ส่วน "ฝึกเอง") โหมดจดเพลง (v0.21–v0.22) ถูกตัดออกทั้งหมด
- **แผนวันนี้ (DailyPlan):** เลือกเวลา 10/20/30/45/60 นาที แอพจัดส่วนตามลำดับ วอร์มนิ้ว → ทดสอบวัดระดับ (ถ้าถึงกำหนด) → ทวนโน้ตและคีย์ (ถ้ามีตัวถึงกำหนด) → ขั้นหลัก → อ่านโน้ตใหม่ → คอร์ด → ฝึกหู → เล่นเพลง วอร์มนิ้ว 2–3 นาทีและทดสอบ 3 นาทีคงที่ ที่เหลือแบ่งตามน้ำหนัก (ขั้นหลักมากที่สุด) ส่วนที่ตรงกับ **ทักษะที่อ่อนที่สุด** ได้เวลาเพิ่ม 1.6 เท่า วันที่มีแค่ 10 นาที เก็บแค่วอร์ม ทดสอบ ขั้นหลัก และส่วนที่อ่อนที่สุด แผนทำครั้งเดียวต่อวัน (เปลี่ยนเวลาแล้วจัดใหม่)
- **ติ๊กจากการฝึกจริงเท่านั้น:** ทุกหน้าฝึกบันทึกเวลาที่เล่นจริงของแต่ละรอบ (หนึ่งรอบนับไม่เกิน 20 นาที) ลงบันทึกรายวันตามชนิดส่วน ส่วนหนึ่งนับว่าเสร็จเมื่อฝึกชนิดนั้นครบ 60% ของนาทีที่วางไว้ ส่วนทดสอบเสร็จเมื่อทดสอบแล้ววันนี้ (ผ่านหรือไม่ก็ได้) ส่วนทวนเสร็จเมื่อไม่มีตัวถึงกำหนด หน้าวันนี้มีปุ่มเดียวไปส่วนถัดไป แสดงนาทีที่ฝึกเทียบกับแผน และ 14 วันล่าสุดเป็นช่องสี่เหลี่ยมธรรมดา (ข้อมูลเฉยๆ ไม่มีรางวัล ไม่มีสถิติต่อเนื่อง)
- **ระดับทักษะ 7 ด้าน (SkillBook):** หาคีย์ (5 ระดับ), อ่านโน้ต (7), จังหวะ (6), อ่านโน้ตใหม่ (7), นิ้วและสเกล (7), หู (8), คอร์ด (7) แต่ละระดับมีแบบทดสอบสั้นและเกณฑ์ตายตัว (ความถูก, เวลาตอบกลาง, สัดส่วนที่ตรงจังหวะ หรือจำนวนครั้งที่เปลี่ยนคอร์ด) และประโยค "ทำได้" ที่บอกว่าระดับนั้นหมายถึงอะไร
  - ระดับได้จากการทดสอบเท่านั้น ไม่ได้จากเวลาฝึกหรือขั้นที่ผ่าน
  - ทดสอบระดับที่ถืออยู่ไม่ผ่านสองครั้งติดกัน ระดับลดลงหนึ่ง
  - ลองระดับเดียวกันที่ไม่ผ่านได้วันละ 2 ครั้ง (โชคไม่ควรตัดสินระดับ)
  - ระหว่างทดสอบ ถ้าเปิดตัวช่วย (ชื่อโน้ต) ผลไม่นับ
  - แผนพาไปทดสอบเอง: ทักษะที่ยังไม่เคยวัดก่อน (วางระดับ) แล้วทักษะที่ทดสอบนานที่สุด ทุก 7 วันต่อทักษะ ระดับสูงสุดทดสอบซ้ำทุก 28 วัน
  - "ภาพรวม" เป็นวลีตรงๆ จากค่าเฉลี่ยสัดส่วนระดับของทักษะที่วัดแล้ว (เพิ่งเริ่มต้น → มือใหม่ → มือใหม่ที่เริ่มเล่นเพลงง่ายได้ → ระดับกลางช่วงต้น → ระดับกลาง) เทียบกับระดับในแอพนี้ ไม่ใช่เกรดสอบดนตรี
  - หน้ารายละเอียดทักษะแสดงผลทดสอบทุกครั้ง ทั้งที่ผ่านและไม่ผ่าน พร้อมตัวเลขที่วัดได้
- **เปียโนอิสระ:** เล่นจากเปียโน MIDI (หรือคีย์บนจอ) ด้วยเสียงของแอพ เช่น ใส่หูฟังแล้วปิดลำโพงเปียโน ปรับความดัง (−18 ถึง +12 dB) ความก้องและความนุ่ม (มือถือ) น้ำหนักคีย์ และทรานสโพส ±12 ครึ่งเสียง ระหว่างเปิดหน้านี้เสียงของแอพเปิดเสมอ ทรานสโพสใช้เฉพาะหน้านี้ ออกแล้วกลับเป็น 0 เวลาที่เล่นจริง (โน้ตห่างกันไม่เกิน 10 วินาที) นับเป็น "เล่นอิสระ" ในนาทีของวัน ไม่มีคะแนน
- **การวัดผลทุก 2 สัปดาห์ (หัวข้อ 12.1):** แทนด้วยการทดสอบระดับรายทักษะข้างบน (ผลเดิมยังเก็บอยู่)

## 3. โครงเซสชันรายวัน (ปรับอัตโนมัติ)

> หมายเหตุ (2026-10-14): โครงเซสชันในหัวข้อนี้ถูกแทนด้วยเซสชันของบันไดฝึก (หัวข้อ 2.5) เก็บไว้เป็นที่มาของสัดส่วนกิจกรรม

| นาที | กิจกรรม | แทร็ก | รายละเอียด |
|---|---|---|---|
| 0–3 | วอร์มอัพ | HANDS | รูปแบบห้านิ้วหรือสเกลที่เพิ่งเรียน พร้อมเมโทรนอม ช้าๆ ผ่อนคลาย |
| 3–8 | ทบทวนการอ่าน | READ_PITCH, KEYS | รายการจาก spaced repetition (สูงสุด 20 รายการ) |
| 8–12 | จังหวะ | READ_RHYTHM | อ่านและเคาะจังหวะ 2–3 แบบ นับเสียงดัง |
| 12–22 | บทเรียน/เพลงปัจจุบัน | HANDS, REPERTOIRE | แบ่งท่อน แยกมือ → รวม ramp tempo สลับ 2–3 จุดที่ยาก |
| 22–26 | อ่านโน้ตใหม่ | READ_PITCH | โน้ตสั้นที่สร้างใหม่ ระดับต่ำกว่าบทเรียนปัจจุบัน 1–2 ขั้น เล่นไม่เกิน 3 รอบ |
| 26–30 | หู + สรุป | EAR | ear training 1 ชุดสั้นๆ และคำถามสรุป 1 ข้อ |

- เวอร์ชัน 15 นาที: วอร์มอัพ 2, ทบทวน 3, เพลง 7, หู/สรุป 3 เวอร์ชัน 45 นาที: เพิ่มเล่นเพลงที่ชอบหรือโปรเจกต์ถอดเพลง (หัวข้อ 9) 15 นาที
- วันที่ 7 ของสัปดาห์: เบาลง ทบทวนและเล่นเพลงที่ชอบ ไม่มีบทใหม่
- ทุก 2 สัปดาห์: checkpoint แบบ benchmark (หัวข้อ 12) ทุกด่านมีการสอบจบด่าน
- แสดง "จำนวนวันที่ฝึก" และนาทีสะสมเป็นข้อมูลเฉยๆ (ผู้ใช้ไม่ต้องการระบบเกม ไม่มีสติกเกอร์ ไม่มีรางวัล) การพักไม่ถูกลงโทษ และข้อความตอนกลับมาฝึกต้องเป็นมิตร
- กฎสำคัญของโค้ช: "ไม่ฝึกสิ่งที่ทำได้แล้วซ้ำๆ" แอพต้องดึงเวลาไปที่ท่อนหรือโน้ตที่ผิดบ่อย (problem-spot detector)

## 4. เส้นทาง 6 ด่าน พิมพ์เขียวบทเรียน

เวลาที่ระบุเป็นการประมาณคร่าวๆ ที่ 30 นาที/วัน **ความก้าวหน้ากำหนดด้วยการผ่านเกณฑ์ ไม่ใช่ปฏิทิน** อย่าสัญญาผู้ใช้ว่าจะถึงเป้าภายในกี่เดือน ในหน้าจอให้เรียกว่า "ประมาณการ" เท่านั้น

ทุกบทเรียนต้องมีฟิลด์: เป้าหมาย (can-do), prerequisites, บล็อกอธิบายภาษาไทย, ตัวอย่างโน้ต+เสียง, ขั้นตอนลองทำพร้อมแอพ, แบบฝึกหัดอ้างอิง exercise type พร้อมพารามิเตอร์, เกณฑ์ผ่าน, รายการที่ต้องเข้า spaced repetition, เคล็ดลับการฝึก 1–2 ข้อ

### ด่าน 1: คีย์บอร์ดและจังหวะพื้นฐาน (ประมาณ 3–4 สัปดาห์)
เป้าหมาย: หาคีย์ใดก็ได้เร็ว นับจังหวะ 4/4 นิ่ง อ่านโน้ต 5 ตัวในตำแหน่ง C ได้
- 1.1 ภูมิศาสตร์คีย์บอร์ด: กลุ่มคีย์ดำ 2 และ 3, หา C และ C ทุกตัว, ตัวอักษร A–G วน, ชื่อโน้ตไทย–อังกฤษ → ผ่าน: หาคีย์ที่สุ่ม 10 ตัวถูกทั้งหมดภายใน 3 วินาทีต่อตัว ใน 2 เซสชัน
- 1.2 ท่านั่ง รูปมือ เลขนิ้ว 1–5 → ผ่าน: เล่นลำดับเลขนิ้วที่แอพสุ่ม (เช่น 1-2-3-4-5, 1-3-2-4) แต่ละมือ 8 ลำดับถูก ที่ 60 bpm
- 1.3 จังหวะคงที่: ชีพจร (pulse) ต่างจากจังหวะ (rhythm), เคาะตามเมโทรนอม 60–80 bpm → ผ่าน: ความเบี่ยงเบนมาตรฐานของเวลา ≤ 80 ms ตลอด 32 จังหวะ หลังหัก latency
- 1.4 ค่าตัวโน้ต: ตัวกลม ตัวขาว ตัวดำ และตัวหยุด, นับ 1-2-3-4 → ผ่าน: อ่านแล้วเคาะ 4 บาร์ถูก 3 ครั้งติด
- 1.5 บรรทัดห้าเส้น ลูกกุญแจซอล จุดอ้างอิง 3 จุด (Bass F, Middle C, Treble G) → ผ่าน: ระบุโน้ตจุดอ้างอิงและข้างเคียง (ระยะ 1 ขั้น) 20 ข้อ ถูก ≥ 90%
- 1.6 อ่านระยะ: ซ้ำ/ขั้น/ข้าม และทิศทางขึ้น–ลง → ผ่าน: ตอบ "ซ้ำ/ขั้น/ข้าม + ทิศทาง" ของโน้ต 3–5 ตัว 10 ชุดถูก ≥ 90% แล้วเล่นตาม
- 1.7 มือขวา ตำแหน่ง C (C–D–E–F–G) อ่านบทสั้น 4 บาร์ ที่ SR ระดับ L1
- 1.8 มือซ้าย ตำแหน่ง C ในกุญแจฟา (C3–G3) อ่านบทสั้น (SR L2)
- 1.9 สองมือง่ายมาก: มือขวาทำนอง มือซ้ายโน้ตยาว
- 1.10 สอบจบด่าน: ภูมิศาสตร์คีย์ + จังหวะ + บทอ่าน 3 บท

### ด่าน 2: กุญแจซอลและทำนองมือขวา (ประมาณ 6–8 สัปดาห์)
เป้าหมาย: อ่านและเล่นทำนองมือขวาช่วง C4–C6 ได้
- 2.1 จุดอ้างอิงเพิ่ม (Treble C5) และการอ่านระยะ 2nd–5th–octave
- 2.2 โน้ตเขบ็ตเดียว (eighth) นับ "1 & 2 &", โน้ตประจุด, ตัวโยง, จังหวะ 3/4
- 2.3 การเปลี่ยนตำแหน่งมือ (C, G, D position), ย้ายมือ
- 2.4 เครื่องหมายแปลงเสียง (♯ ♭), คีย์ซิกเนเจอร์ G และ F
- 2.5 สเกลโน้ตเปลี่ยนนิ้ว: การไขว้นิ้วโป้ง, สเกล C เมเจอร์หนึ่งอ็อกเทฟมือขวา
- 2.6 จังหวะ 8 แบบพื้นฐานต่อหนึ่งจังหวะ ให้ครบก่อนไปต่อ (ดูหัวข้อ 5)
- 2.7 legato/staccato และ dynamics เบื้องต้น (ตามข้อกำหนดในหัวข้อ 2.3 ข้อ 4 เรื่องแรงกด)
- 2.8 เพลงเรียน 6 เพลง ที่ใช้ทำนองสาธารณสมบัติ (ดูหัวข้อ 5.4) SR L3–L4
- 2.9 สอบจบด่าน

### ด่าน 3: กุญแจฟาและมือซ้าย (ประมาณ 6–8 สัปดาห์)
เป้าหมาย: อ่านและเล่นมือซ้ายช่วง C2–C4 และรูปแบบประกอบง่ายๆ ได้
- 3.1 บรรทัดกุญแจฟา จุดอ้างอิง F3, C3, C4 และการอ่านระยะ
- 3.2 มือซ้ายตำแหน่ง C และ G, ทำนองมือซ้าย
- 3.3 รูปแบบมือซ้าย: โน้ตตัวเดียวยาว, 1–5, อาร์เพจจิโอ 1-5-8
- 3.4 สเกล C เมเจอร์มือซ้าย
- 3.5 อ่านข้ามบรรทัด (สลับอ่านมือขวา/ซ้ายทีละบาร์)
- 3.6 ความอิสระของสองมือด้านจังหวะ: เคาะจังหวะต่างกันสองมือ (ดูหัวข้อ 5)
- 3.7 เพลงเรียน SR L5, สอบจบด่าน

### ด่าน 4: บรรทัดคู่และสองมือ (ประมาณ 10–12 สัปดาห์)
เป้าหมาย: เล่นสองมือจากโน้ตจริงได้ในคีย์ C, G, F, D และ B♭
- 4.1 Grand staff เส้นน้อย (ledger lines) รอบ Middle C
- 4.2 สองมือรวมกัน: ทำนอง + ประกอบเรียบ, การเคลื่อนที่ตรงข้ามกัน
- 4.3 คีย์ซิกเนเจอร์และสเกลเมเจอร์ C, G, F, D, B♭ (แยกมือ → รวม), วงกลมควินท์เบื้องต้น
- 4.4 จังหวะ 2/4, 3/4, 4/4, 6/8, จังหวะซิงโคเพชันง่ายๆ
- 4.5 ซัสเทนเพดัล (ผู้ใช้มีแพดเดิ้ล), articulation
- 4.6 การอ่านคอร์ดแนวตั้ง (triads เป็นชั้นเสียง 3)
- 4.7 เพลงเรียน SR L6, อ่านโน้ตใหม่
- 4.8 สอบจบด่าน (เล่นเพลงสองมือ 2 เพลง)

### ด่าน 5: คอร์ดและ lead sheet (ประมาณ 10–12 สัปดาห์)
เป้าหมาย: เล่นเพลงจากทำนอง + สัญลักษณ์คอร์ดได้
- 5.1 โครงสร้างไทรแอด: เมเจอร์/ไมเนอร์/ดิมินิช/ออกเมนเต็ด
- 5.2 คอร์ดในคีย์ C, G, F, D, B♭, A, E (ลำดับตามความถี่ของเพลงเป้าหมาย ดูหัวข้อ 9) ท่าราก → กลับเสียง → เลือกกลับเสียงที่เคลื่อนน้อยที่สุด
- 5.3 อ่านสัญลักษณ์คอร์ด, สแลชคอร์ด (เช่น C/E), sus, add9
- 5.4 คอร์ดเสียงในคีย์ (I ii iii IV V vi vii°) และเลขโรมัน
- 5.5 ย้ายโปรเกรสชันเดียวกันไป 3–4 คีย์
- 5.6 คอร์ดเซเวนท์: maj7, m7, dominant 7
- 5.7 ขั้นบันไดรูปแบบประกอบ (ดูหัวข้อ 8)
- 5.8 อารมณ์จังหวะ: 8 บีต, บัลลาด, 16 บีต
- 5.9 ear: ฟังโปรเกรสชัน
- 5.10 เล่น lead sheet ตามแบ็กกิ้งแทร็กที่แอพสร้าง, สอบจบด่าน

### ด่าน 6: Piano Pop / J-Pop และเพลงเป้าหมาย (ต่อเนื่อง ไม่มีวันจบ)
เป้าหมาย: เรียนเพลงใหม่ของ Hello! Project และ AKB48 ได้เองด้วย pipeline ในหัวข้อ 9
- 6.1 โปรเกรสชันที่พบบ่อยใน J-Pop (หัวข้อ 8) ฝึกฟังและเล่นในหลายคีย์
- 6.2 โครงเพลง: intro / verse / pre-chorus / chorus / bridge, การอ่านฟอร์ม
- 6.3 คอร์ดนอกคีย์ (borrowed chords), คอร์ดข้างเคียง, การเปลี่ยนคีย์ขึ้น
- 6.4 รูปแบบประกอบขั้นสูง: 8 บีตอ็อกเทฟเบส, อาร์เพจจิโอ 8 ตัว, ซิงโคเพชันแบบ 16
- 6.5 อินโทร/เอาท์โทร/ฟิลล์
- 6.6 **Capstone A**: เรียบเรียงเพลงสไตล์ J-Pop ต้นฉบับ (แอพให้ผู้ใช้เขียนเอง มีเทมเพลตให้ ไม่ใช่เพลงจริง)
- 6.7 **Capstone B**: ถอดเพลงที่ผู้ใช้เลือก 1 เพลง (คอร์ดท่อนคอรัส + ทำนอง) แล้วเล่นครบเพลง บันทึกลงคลังเพลง

## 5. ตัวสร้างแบบฝึกหัด (Exercise Engine)

ตัวสร้างต้องผลิตโจทย์ **ใหม่ไม่ซ้ำ** ตามพารามิเตอร์ ไม่ใช้โจทย์ตายตัว

### 5.1 ชนิดแบบฝึกหัด
- `E_KEYFIND` หาคีย์ที่แอพบอก (ชื่อโน้ต/โด-เร-มี) วัดความเร็วและความถูกต้อง
- `E_NOTEID` เห็นโน้ตบนบรรทัด กดคีย์นั้น (ผ่าน MIDI หรือหน้าจอ) พูลโน้ตค่อยๆ ขยายตามจุดอ้างอิง
- `E_INTERVAL_READ` เห็นโน้ตคู่ ตอบ ซ้ำ/ขั้น/ข้าม/ทิศทาง แล้วเล่น
- `E_RHYTHM_TAP` เห็นจังหวะ นับเสียงดัง เคาะบนคีย์เดียว (หรือกดหน้าจอ)
- `E_RHYTHM_ECHO` ฟังจังหวะ 1–2 บาร์ แล้วเคาะตาม
- `E_FINGER_PATTERN` เล่นรูปแบบนิ้วตามเลขที่แสดง
- `E_READ_PIECE` อ่านเล่นบทสั้นที่สร้างใหม่ (ตัวสร้างด้านล่าง)
- `E_SECTION_PRACTICE` ซ้ำท่อน แยกมือ ramp tempo
- `E_HANDS_BUILD` รวมสองมือทีละขั้น (ดูหัวข้อ 6.5)
- `E_CHORD_BUILD` สร้างคอร์ดจากชื่อ (เร็วและถูก)
- `E_CHORD_CHANGE` เปลี่ยนคอร์ดในเวลา 60 วินาที นับจำนวนครั้งที่ถูก
- `E_COMP_PATTERN` เล่นรูปแบบประกอบตามโปรเกรสชันและแบ็กกิ้งแทร็ก
- `E_TRANSPOSE` ย้ายวลีสั้นไปคีย์อื่น
- `E_EAR_*` ดูหัวข้อ 11

### 5.2 ตัวสร้างโน้ตสำหรับอ่าน (Sight-reading generator)
สร้างบทสั้น 4–8 บาร์ ตามระดับ ห้ามสร้างบทที่เล่นไม่ได้ (นิ้วกระโดดเกินตำแหน่ง, เสียงซ้ำจนน่าเบื่อมากเกิน) และต้องมีเทสต์ยืนยัน

| ระดับ | มือ | ตำแหน่ง | ระยะที่ใช้ | จังหวะ | จังหวะประจำ | บาร์ |
|---|---|---|---|---|---|---|
| L1 | ขวา | C | ซ้ำ ขั้น | ♩ 𝅗𝅥 𝅝 | 4/4 | 4 |
| L2 | ซ้าย | C (ฟา) | ซ้ำ ขั้น | ♩ 𝅗𝅥 𝅝 | 4/4 | 4 |
| L3 | ขวา | C, G | + เทิร์ด | + ♪♪, ตัวหยุด ♩ | 3/4, 4/4 | 4–8 |
| L4 | ขวา/ซ้าย | ย้ายมือ 1 ครั้ง | + 4th 5th | + 𝅗𝅭. ตัวโยง | 3/4, 4/4 | 8 |
| L5 | สองมือ (สลับบาร์ → พร้อมกัน) | C, G, F | เทิร์ด | ซ้าย 𝅝/𝅗𝅥 | 4/4 | 8 |
| L6 | สองมือ | C, G, F, D, B♭ | + อาร์เพจจิโอซ้าย | + 6/8 | 4/4, 6/8 | 8 |
| L7 | สองมือ + คอร์ด | รวมเส้นน้อย | ไทรแอด | + ซิงโคเพชันง่าย | 4/4 | 8 |
| L8 | lead sheet: ทำนอง + สัญลักษณ์คอร์ด | คีย์ที่ใช้ในเพลงเป้าหมาย | + 7th, slash | 8 บีต | 4/4 | 8–16 |

### 5.3 ชุดจังหวะ 8 แบบต่อหนึ่งจังหวะ (ด่าน 2.6 ต้องครบก่อนไปต่อ)
แหล่งข้อมูลที่ผมพบบอกแค่ว่าครูเริ่มสอนจากจังหวะพื้นฐานราว 8 แบบต่อหนึ่งจังหวะ แต่ไม่ได้ระบุว่าคือแบบไหน **ชุดด้านล่างผมกำหนดเอง** (นับต่อหนึ่งจังหวะ แบ่ง 4 ช่อง "1 e & a"):
1. โน้ตตัวดำ (1 ตัว)
2. สองตัวเขบ็ตหนึ่งชั้น (1 &)
3. สี่ตัวเขบ็ตสองชั้น (1 e & a)
4. เขบ็ตหนึ่งชั้น + เขบ็ตสองชั้น 2 ตัว (1 & a)
5. เขบ็ตสองชั้น 2 ตัว + เขบ็ตหนึ่งชั้น (1 e &)
6. ประจุดเขบ็ตหนึ่งชั้น + เขบ็ตสองชั้น (1 a)
7. เขบ็ตสองชั้น + เขบ็ตหนึ่งชั้น + เขบ็ตสองชั้น (1 e a)
8. ตัวหยุดเขบ็ตหนึ่งชั้น + เขบ็ตหนึ่งชั้น (ตกจังหวะยก "&")
ไตรเพลต (triplet) แยกเป็นบทเสริมหลังชุดนี้
- ฝึกทีละแบบ: พูดเสียงก่อน → เคาะเท้า + พูด → เคาะมือ → เล่นบนคีย์เดียว → ใส่ระดับเสียง แล้วค่อยผสมหลายแบบในบาร์เดียว

### 5.4 เนื้อหาเพลงเรียน (ห้ามละเมิดลิขสิทธิ์)
- ใช้เฉพาะ: เพลงที่เราแต่งเอง (ต้นฉบับ) และทำนองที่เป็นสาธารณสมบัติ (เช่น เพลงพื้นบ้าน เพลงคลาสสิกที่หมดลิขสิทธิ์)
- **ห้ามใส่โน้ตหรือเนื้อร้องของเพลง Hello! Project / AKB48 ลงในแอพ** ผู้ใช้เป็นคนใส่เองผ่านเครื่องมือเขียนโน้ต/นำเข้า MusicXML-MIDI (ดูหัวข้อ 9)

## 6. เกณฑ์ผ่านและกฎความก้าวหน้า

### 6.1 "เล่นสะอาด" (clean run)
โน้ตถูก ≥ 95% และอยู่ในเกณฑ์เวลาตามด่านอย่างน้อย 90% ของโน้ต และหยุดชะงักนาน > 1 จังหวะไม่เกิน 1 ครั้ง

### 6.2 เกณฑ์เวลาตามด่าน (หลังหัก latency, ที่ tempo ≤ 80 bpm)
ด่าน 1 ±150 ms, ด่าน 2 ±120, ด่าน 3 ±110, ด่าน 4 ±100, ด่าน 5–6 ±90 ที่ tempo สูงกว่า 80 bpm ใช้ค่าน้อยกว่าระหว่างค่าข้างต้นกับ 25% ของความยาวหนึ่งจังหวะ มีโหมด strict/normal/forgiving คูณ 0.75 / 1 / 1.3

### 6.3 Tempo ramp
เริ่มที่ 50–60% ของ tempo เป้าหมาย (ไม่ต่ำกว่า 40 bpm) เพิ่ม 5 bpm (หรือ 10% ถ้าเกิน 80 bpm) หลังเล่นสะอาด 3 รอบติด ลดลงหนึ่งขั้นหลังพลาด 2 รอบติด

### 6.4 ผ่านบทเรียน
เล่นสะอาด 3 รอบติดที่ tempo เป้าหมาย **ใน 2 วันที่ต่างกัน** (เพื่อให้มีช่วงเว้นระยะ) และแบบฝึกหัดประกอบผ่านตามเกณฑ์ของบทนั้น ผู้ใช้ขอ "สอบข้าม" (test-out) บทที่ตนรู้แล้วได้ครั้งเดียว
ปลดล็อกบทถัดไปเมื่อผ่านบทก่อน

### 6.5 การรวมสองมือทีละขั้น (`E_HANDS_BUILD`)
ขั้น 1 อ่านท่อนโดยสองมือ 1–2 รอบเพื่อทำความรู้จัก → ขั้น 2 มือขวาคนเดียว (วลีสั้น) → ขั้น 3 มือซ้ายคนเดียว → ขั้น 4 สองมือช้ามาก (50%) → ขั้น 5 ramp tempo ผู้ใช้เลือกข้ามขั้น 2–3 ได้ถ้าท่อนง่าย

### 6.6 Spaced repetition (กล่อง 5 ระดับ)
ช่วงทบทวนเริ่มต้น: กล่อง 1 = 1 วัน, 2 = 2 วัน, 3 = 4 วัน, 4 = 8 วัน, 5 = 16 วัน ตอบถูกและเร็วพอ (≤ 3 วินาที สำหรับการอ่านโน้ต) → ขึ้นหนึ่งกล่อง ตอบผิดหรือช้า → กลับกล่อง 1 สูงสุด 20 รายการต่อเซสชัน จัดลำดับโดยให้น้ำหนักรายการที่ผิดล่าสุด
รายการที่ใช้: ชื่อโน้ตแต่ละกุญแจ, ตำแหน่งคีย์, ระยะ (interval) อ่าน, ไทรแอดและคอร์ด, คีย์ซิกเนเจอร์, รายการ ear

### 6.7 ปรับความยากอัตโนมัติ
ตั้งเป้าให้อัตราถูกของแบบฝึกหัดอ่านและหูอยู่ราว 80–90% (ค่าออกแบบ ไม่ใช่ผลวิจัย) ถูก > 92% ติดกันหลายรอบ → ขยายพูล/เร่งความเร็ว ถูก < 70% → ลดลงและแนะนำทบทวนบทก่อนหน้า

### 6.8 การตัดสินใจเมื่อสลับหัวข้อ (interleaving)
ใน 10 นาทีของส่วนบทเรียน/เพลง: ฝึกท่อนเดียวจนเล่นสะอาดครั้งแรก จากนั้นสลับระหว่างท่อนที่ยาก 2–3 จุด จุดละ 2–4 นาที ผู้ใช้ปิดได้ในตั้งค่า

## 7. โค้ชและข้อความย้อนกลับ

ข้อความเป็นภาษาไทย สั้น บอกสาเหตุที่น่าจะเป็นและสิ่งที่ลองทำต่อ ไม่ตำหนิ
- โน้ตผิดบ่อยที่โน้ตเดียวกัน → "โน้ต {X} พลาดบ่อย เดี๋ยวฝึกโน้ตนี้แยกให้ 2 นาที"
- ถูกแต่เร็ว/ช้ากว่าเมโทรนอมสม่ำเสมอ → ปรับ latency calibration ก่อน แล้วค่อยบอกว่า "ลองนับเสียงดังหรือเคาะเท้า"
- ติดที่รอยต่อระหว่างสองท่อน → เสนอ "chaining" เล่นคร่อมรอยต่อ 1–2 บาร์
- ผิดเฉพาะมือซ้าย → แนะนำแยกมือซ้ายก่อน
- เล่นเร็วเกินไปแล้วพลาด → "ลดเหลือ {tempo} bpm ก่อน"
- หลังเซสชัน: ถามคำถามเดียว เช่น "ตรงไหนรู้สึกยากที่สุดวันนี้" เพื่อเก็บข้อมูลและปรับแผนวันถัดไป
- ข้อความสอนวิธีฝึกสั้นๆ สอดแทรกตามสถานการณ์ เช่น ฝึกช้า ไม่เล่นทั้งเพลงวนๆ ฝึกส่วนที่ยากมากกว่าส่วนที่ทำได้แล้ว

## 8. แทร็ก Pop / J-Pop: โปรเกรสชัน รูปแบบประกอบ และ lead sheet

### 8.1 โปรเกรสชันที่ต้องฝึกฟังและเล่นในหลายคีย์ (ตัวอย่างในคีย์ C)
| ชื่อ | ระดับขั้น | ตัวอย่างในคีย์ C |
|---|---|---|
| Axis / Pop | I–V–vi–IV | C–G–Am–F |
| Axis แบบเริ่มที่ vi | vi–IV–I–V | Am–F–C–G |
| วงจร (50s) | I–vi–IV–V | C–Am–F–G |
| Canon | I–V–vi–iii–IV–I–IV–V | C–G–Am–Em–F–C–F–G |
| โกมุโร (小室進行) | vi–IV–V–I | Am–F–G–C |
| ทางหลวง (王道進行) | IVM7–V7–iii7–vi | FM7–G7–Em7–Am |
| ปิดเต็มวงกลมควินท์ | IVM7–V7–iii7–vi–ii7–V7–I | FM7–G7–Em7–Am–Dm7–G7–C |
| ii–V–I | ii7–V7–IM7 | Dm7–G7–CM7 |

แหล่งสอนแต่งเพลงญี่ปุ่นระบุว่า "ทางหลวง" และ "โกมุโร" เป็นโปรเกรสชันยอดนิยมในป็อปญี่ปุ่น (ยังไม่ได้ตรวจว่า Hello! Project/AKB48 ใช้บ่อยแค่ไหน) แอพต้องสอนให้ **ฟังออกว่าเป็นแบบไหน** (ear) และ **เล่นออก** (เล่นคอร์ดและรูปแบบประกอบ)

### 8.2 ขั้นบันไดรูปแบบประกอบมือซ้าย (จากง่ายไปยาก)
1. โน้ตรากยาว หรือรากกับควินท์ (C–G–C)
2. อาร์เพจจิโอ 1-5-8
3. คอร์ดแบบบล็อกทั้งห้อง
4. คอร์ดแบ่งตามจังหวะ (comping) 4 จังหวะ
5. เบสอ็อกเทฟ + คอร์ดตกจังหวะยก (off-beat)
6. อาร์เพจจิโอ 8 ตัวต่อบาร์ ไหลต่อเนื่อง
7. ซิงโคเพชันแบบ 16 บีต
แต่ละขั้นฝึกในลำดับ: **มือซ้ายคนเดียว → มือขวาคนเดียว (ทำนอง) → สองมือพร้อมแบ็กกิ้งแทร็ก** รีวิวของผู้เรียนบางคนบอกว่าติดที่การจับคู่สองมือ จึงให้มี `E_COMP_PATTERN` แบบเปลี่ยนรูปแบบมือซ้ายทีละชนิดคู่กับทำนองเดิม

### 8.3 ตัวเลือกมือซ้ายสำหรับ lead sheet (ตามลำดับง่าย → สมบูรณ์)
โน้ตตัวเดียว/ควินท์ → อาร์เพจจิโอ 1-5-8 → คอมปิงแบ่งตามจังหวะ

### 8.4 Capstone A (6.6)
เทมเพลตเพลง 32 บาร์: intro 4, verse 8, pre-chorus 4, chorus 8, outro 4 ในโปรเกรสชัน "ทางหลวง" ให้ผู้ใช้เขียนทำนองเอง (ห้ามเลียนทำนองเพลงจริง) แล้วเล่นพร้อมรูปแบบประกอบ 2 แบบ บันทึกไว้ดูความก้าวหน้า

## 9. สายเป้าหมาย: Hello! Project และ AKB48

### 9.1 สรุปว่าต้องไป "สายไหน"
**สาย Pop piano แบบ lead sheet + ถอดเพลงจากหู** ไม่ใช่สายคลาสสิก คือ:
1. อ่านทำนองบนกุญแจซอลได้คล่อง
2. เล่นคอร์ดประกอบหลายรูปแบบได้ (ไทรแอด เซเวนท์ สแลชคอร์ด)
3. ได้หลายคีย์ รวมคีย์ที่มีชาร์ป/แฟลตมาก
4. จังหวะแม่นที่ tempo ราว 100–160 bpm
5. ถอดคอร์ดและทำนองจากหูได้ เพื่อเรียนเพลงที่ไม่มีโน้ต

### 9.2 สิ่งที่ผมพบจากการค้นหา (และความมั่นใจ)
- **จำนวนเพลงมาก**: นับเฉพาะเพลงโมเดิร์นมุซึเมะที่ซึนกุแต่งเนื้อ ณ มิถุนายน 2019 ได้ 286 เพลง (หลังหักเวอร์ชันซ้ำ เพลงสั้นในละครเวที และเพลงเดี่ยวของสมาชิก) และฮัลโลโปรทั้งหมดยังมีเพลงของศิลปินและกลุ่มอื่นอีกมาก ผลคือ "เล่นส่วนใหญ่" ไม่ใช่เรื่องท่องโน้ตทีละเพลง (ความมั่นใจสูง)
- **โน้ตเปียโนทางการมีขายแบบเพลงเดี่ยว** เช่นบริการ ぷりんと楽譜 ของยามาฮ่าที่มีโน้ตเปียโนโซโลหลายระดับ และมีหนังสือรวมเพลงระดับเริ่มต้นที่มีเพลง AKB48 รวมอยู่ (ความมั่นใจสูงว่ามีบางเพลง แต่ **ไม่รู้ว่ามีครบกี่เพลงของสองวงนี้** ต้องให้ผู้ใช้ตรวจเอง)
- **ระดับความยาก**: บนเว็บคอร์ดที่ผู้ใช้ส่งขึ้นเอง "Heavy Rotation" ติดป้ายระดับกลาง และ "New Ship" ติดป้ายระดับสูง ป้ายเหล่านี้ผู้ใช้เว็บเป็นคนใส่ จึงเป็นเพียงสัญญาณคร่าวๆ (ความมั่นใจต่ำ)
- **คีย์**: Heavy Rotation อยู่ในคีย์ E เมเจอร์ (สี่ชาร์ป) ตามฐานข้อมูล Hooktheory และเว็บวิเคราะห์เพลงระบุว่าทำนองของเพลงตัวอย่างหลายเพลงอยู่ในช่วงเสียงค่อนข้างสูง ผมอนุมานเองว่า (ยังไม่ได้ตรวจ) เพลงจำนวนมากอาจไม่ได้อยู่ในคีย์ C จึงควรเผื่อ **คีย์ที่มีชาร์ป/แฟลตมาก** ไว้ในหลักสูตร (ยืนยันแล้วเฉพาะ Heavy Rotation เพลงเดียว ยังไม่ได้ตรวจทั้งแคตตาล็อก)
- **Tempo**: เพลงตัวอย่างที่ผมเห็นข้อมูลอยู่ราว 104–158 bpm (เช่น 104, 118, 121, 140, 153, 158) ตัวเลขมาจากเว็บวิเคราะห์เพลงแบบอัตโนมัติ อาจคลาดเคลื่อน (ความมั่นใจปานกลาง)
- **ช่วงเสียงทำนอง**: เพลงตัวอย่างส่วนใหญ่ทำนองอยู่ราว C4–D5 (บางเพลงลงไป F3 หรือขึ้นถึง D5–D#5) ซึ่งหมายความว่าการอ่านกุญแจซอลช่วง C4–D5 ให้คล่องคุ้มค่ามาก ข้อมูลได้จากการวิเคราะห์เสียงร้อง ค่าอาจเพี้ยนเล็กน้อย (ความมั่นใจปานกลาง)
- **โปรเกรสชัน**: ป็อปญี่ปุ่นใช้ "ทางหลวง" (IVM7–V7–iii7–vi) และ "โกมุโร" (vi–IV–V–I) มาก ตามบทความและแหล่งสอนแต่งเพลง (ความมั่นใจสูงว่าเป็นโปรเกรสชันยอดนิยม แต่ **ไม่ได้ยืนยันว่าสองวงนี้ใช้บ่อยแค่ไหน**)
- **สไตล์ซึนกุ**: สมาชิกวงคนหนึ่งเล่าในบทสัมภาษณ์ว่าเพลงของซึนกุมักมีเบสกับคอร์ดที่ไม่ตามทำนองตรงๆ ฟังแล้วมีเอกลักษณ์ นี่เป็นความเห็นของคนเดียว ไม่ใช่การวิเคราะห์ทางทฤษฎี (ความมั่นใจต่ำ) แต่ถ้าจริง ก็ยิ่งต้องมี ear training เรื่องเบสและคอร์ดนอกคีย์
- **สิ่งที่ผมหาไม่เจอ**: การวิเคราะห์ฮาร์โมนีของ Hello! Project/AKB48 ทั้งแคตตาล็อกที่เชื่อถือได้ ดังนั้นอย่าถือว่า 9.2 เป็นคำตอบสุดท้าย ให้แอพวิเคราะห์เพลงที่ผู้ใช้เลือกเองแล้วปรับเนื้อหา (9.4)

### 9.3 ผลต่อหลักสูตร
- ช่วงอ่านทำนอง: เน้น C4–D5 ก่อน แล้วขยายลง F3 ขึ้นถึง E5 ในด่าน 2 และ 4
- ลำดับคีย์ที่สอน: C → G → F → D → B♭ → A → E → E♭ → A♭ (ใส่ในด่าน 4–5 ตามลำดับ) นี่เป็นลำดับเริ่มต้นที่ผมกำหนดเองตามความง่ายของคีย์ซิกเนเจอร์ ให้ปรับตามเพลงที่ผู้ใช้เลือกจริง (9.4, 9.6) เพลงเป้าหมายชุดแรกมี A♭ และ E♭ จึงต้องเข้าให้ทันก่อนถึงเพลงนั้น
- โหมด transpose: ผู้ใช้ฝึกเพลงในคีย์ที่ง่ายกว่า (เช่น C) ก่อน แล้วค่อยย้ายกลับคีย์ต้นฉบับ (`E_TRANSPOSE`)
- คอร์ดที่ต้องสอนก่อนถึงเพลงเป้าหมายชุดแรก: maj9, add9, sus4, m7♭5, aug, 7♭9, 13th, สแลชคอร์ด และโดมิแนนท์ข้างเคียง (เช่น E7, D7 ในคีย์ C)
- เซเวนท์คอร์ดและสแลชคอร์ดมาเร็ว (ด่าน 5)
- จังหวะ: ผู้ใช้ต้องเล่นสม่ำเสมอที่ 100–160 bpm ให้ tempo เป้าหมายของบทเรียนด่าน 5–6 ครอบคลุมช่วงนี้ และฝึกจังหวะ 16 และซิงโคเพชัน
- ear training เน้นโปรเกรสชัน เบสไลน์ และคอร์ดนอกคีย์ (ด่าน 6.3)

### 9.4 เครื่องมือในแอพ: คลังเพลง + ตัววิเคราะห์ความยาก (Song Ladder)
- ผู้ใช้เพิ่มเพลงเองด้วย: เครื่องมือเขียนโน้ต, นำเข้า MusicXML/MIDI ที่ผู้ใช้มีสิทธิ์ใช้ (เช่น ซื้อโน้ตทางการมาเอง) หรือพิมพ์คอร์ดเอง ใช้เพื่อฝึกส่วนตัวเท่านั้น แอพไม่เผยแพร่ ไม่ดึงโน้ตจากเว็บ
- แอพคำนวณ **คะแนนความยากของเพลง** จากข้อมูลที่ผู้ใช้ใส่ เพื่อเรียงลำดับ "เพลงถัดไปที่ควรฝึก":
  - จำนวนชาร์ป/แฟลต, tempo, ความหนาแน่นของจังหวะ (โน้ต/จังหวะ และสัดส่วนซิงโคเพชัน), ช่วงเสียงทำนอง, จำนวนชนิดคอร์ดไม่ซ้ำและคอร์ดนอกคีย์, จำนวนครั้งที่ต้องย้ายมือ, ความซับซ้อนของมือซ้าย
  - เทียบกับระดับทักษะปัจจุบันของผู้ใช้ในแต่ละแทร็ก แล้วแสดงว่า "ยังขาดอะไร" เช่น "เพลงนี้ใช้คีย์ E เมเจอร์ ซึ่งคุณยังไม่ผ่านบท 5.2 สำหรับ E"
- ผู้ใช้เลือก 5–10 เพลงที่อยากเล่นก่อน แอพวิเคราะห์ แล้วสร้าง "แผนไปเพลงเป้าหมาย" บอกบทเรียนที่ต้องผ่านก่อน (ก่อนมีข้อมูลนี้ ใช้แผนเริ่มต้นในหัวข้อ 4)

### 9.5 ขั้นตอนเรียนเพลงใหม่ (Song-learning pipeline)
รอบละ 7 วัน (ฝึกวันละ 10–15 นาทีในส่วนโปรเจกต์ ที่เหลือเป็นแผนปกติ)
1. **วันที่ 1**: ฟังทั้งเพลง แล้วทำแผนผังฟอร์ม (intro/verse/chorus) และหาคีย์ (ใช้ตัวช่วย: เล่นโน้ตที่ฟังรู้สึก "จบ" บนเปียโน)
2. **วันที่ 2**: ถอดคอร์ดท่อนคอรัสเป็นเลขโรมัน ใช้ชุดเครื่องมือฟังและวนลูปช้าลง (ข้อ 11.3)
3. **วันที่ 3**: ถอดทำนองท่อนคอรัสเป็นวลีสั้นๆ ทีละ 2 บาร์ ตรวจด้วยการเล่น
4. **วันที่ 4**: เล่นคอร์ดประกอบรูปแบบง่ายตามโปรเกรสชัน
5. **วันที่ 5**: รวมทำนอง + ประกอบ ช้า 50%
6. **วันที่ 6**: ramp tempo และเก็บท่อนที่ยากแยกฝึก
7. **วันที่ 7**: เล่นทั้งท่อนคอรัสสะอาด 3 รอบ แล้วขยายไปท่อนอื่น
ถ้ามีโน้ตทางการ ใช้โหมดอ่านแทนขั้น 1–3 แต่ยังต้องทำขั้น 2 (ถอดคอร์ดเป็นเลขโรมัน) เพื่อสร้างทักษะไปเพลงต่อไป

### 9.6 เพลงเป้าหมายชุดแรกของผู้ใช้ (ข้อมูลที่ตรวจแล้วบางส่วน)
**ยืนยันจากผู้ใช้แล้ว (2026-10-11):** เริ่มจาก 2 เพลง คือ **I WISH (เวอร์ชันโมเดิร์นมุซึเมะ)** และ **心のプラカード (AKB48)** ส่วน **恋愛レボリューション21** เป็นเพลงถัดไปทีหลัง ผู้ใช้ชอบ Hello! Project และ AKB48 ทั้งหมด จึงไม่จำกัดเพลง และเล่นอย่างเดียว ไม่ร้อง

ผู้ใช้ไม่มีโน้ตทางการและไม่คิดจะซื้อ เป้าหมายคือฝึกจนทำโน้ตเวอร์ชันของตัวเองได้ ดังนั้นเพลงจริงใช้เส้นทางแกะเอง (pipeline 9.5) ที่ผู้ใช้ป้อนผลลงแอพเอง ส่วนการอ่านโน้ตฝึกจากแบบฝึกที่แอพสร้างและเพลงโดเมนสาธารณะ

**หมายเหตุลำดับ:** ผู้ใช้พูดถึง I WISH ก่อน ถือเป็นเพลงปลายทางแรก แต่ตามการวิเคราะห์ด้านล่าง 心のプラカード น่าจะเข้าถึงได้เร็วกว่า แอพให้ผู้ใช้เลือกลำดับเอง และแสดง "ยังขาดอะไร" ของทั้งสองเพลงคู่กัน

**ลำดับที่แนะนำ (ผมตัดสินจากช่วงเสียง เทมโป และความซับซ้อนของคอร์ดที่พบ ไม่ใช่ข้อมูลความยากทางการ):**
1. **心のプラカード**: ทำนองช่วงแคบที่สุดของชุดนี้ (หนึ่งอ็อกเทฟ) เทมโปช้า เป็นเพลงแรกที่เหมาะใช้ฝึก pipeline หัวข้อ 9.5 เพราะยังไม่มีข้อมูลคีย์/คอร์ด ผู้ใช้ต้องถอดจากหูเอง (เป็นแบบฝึกจริง) เล่นแบบทำนอง + คอร์ดบล็อกหลังผ่านด่าน 5.4
2. **I WISH**: ทำนองแคบ แต่ฮาร์โมนีหลากหลายและมีการเปลี่ยนคีย์/เทมโป ต้องผ่านบท 5.6 (เซเวนท์) และ 6.3 (คอร์ดนอกคีย์ การเปลี่ยนคีย์) และคีย์ A♭/E♭ ก่อน ฝึกเป็นท่อนๆ ในคีย์ที่ง่ายกว่าด้วยโหมด transpose ก่อนได้
3. **恋愛レボリューション21**: เทมโปเร็วที่สุด (133) ทำนองกว้างที่สุด และฮาร์โมนีมีโดมิแนนท์ข้างเคียงมาก ควรเป็นเพลงที่ 3 หลังผ่านด่าน 6.1–6.4 ฝึกที่ 60–70% ของเทมโปก่อนตาม tempo ramp

ยังไม่ควรสัญญาเวลาว่าจะเล่นได้เมื่อไร ให้แอพคำนวณ "ยังขาดอะไร" จากหัวข้อ 9.4 แทน

### 9.7 Can-do ของสายเป้าหมาย
- ฟังเพลงที่ไม่เคยเล่น แล้วหาคีย์และโปรเกรสชันท่อนคอรัสได้ภายใน 20 นาที
- เล่น lead sheet เพลง 120 bpm ครบเพลงโดยไม่หยุด
- อ่านโน้ตทำนองใหม่ในกุญแจซอลที่ระดับ L7 ได้ที่ 70 bpm
- เปลี่ยนคอร์ดที่พบบ่อย 12 ตัวในคีย์ที่ฝึกได้ภายใน 60 วินาที ≥ 20 ครั้งถูก

## 10. ตัวอย่างบทเรียนมาตรฐาน: บท 1.1 "ภูมิศาสตร์ของคีย์บอร์ด"

**เป้าหมาย:** หาคีย์ใดก็ได้ที่ชื่อบอก เร็วและไม่ต้องนับ
**เวลา:** ประมาณ 12 นาที | **แทร็ก:** KEYS | **Prerequisites:** ไม่มี

**1. อธิบาย (ไม่เกิน 1 นาที)**
คีย์บอร์ดมีคีย์ขาวและคีย์ดำ คีย์ดำเรียงเป็นกลุ่ม 2 ตัวและ 3 ตัว สลับกันไป ใช้กลุ่มดำเป็นป้ายบอกตำแหน่ง
- คีย์ขาว **C (โด)** อยู่ซ้ายมือติดกับกลุ่มดำ 2 ตัว
- D (เร) อยู่ระหว่างคีย์ดำ 2 ตัวนั้น และ E (มี) อยู่ขวามือของกลุ่ม 2 ตัว
- F (ฟา) อยู่ซ้ายมือติดกลุ่มดำ 3 ตัว ส่วน G (ซอล), A (ลา) อยู่ระหว่างคีย์ดำของกลุ่ม 3 ตัว และ B (ที) อยู่ขวามือของกลุ่ม 3 ตัว
- ชื่อ A–G วนซ้ำไปเรื่อยๆ เสียงสูงไปทางขวา เสียงต่ำไปทางซ้าย
- C ที่อยู่ใกล้กลางคีย์บอร์ดเรียกว่า Middle C (C4) เป็นจุดอ้างอิงสำคัญของการอ่านโน้ต

**2. ลองพร้อมแอพ (ไม่ตัดสินคะแนน)**
- แอพไฮไลต์คีย์ C ทีละตัวพร้อมเล่นเสียง ให้กดตาม เมื่อกดถูกจะขึ้นชื่อโน้ตสองแบบ (C / โด)
- แอพถาม "C ทั้งหมดมีกี่ตัวบนคีย์บอร์ดของคุณ" (นับจากช่วงคีย์ที่ตั้งค่าไว้ ไม่ใช่เลขตายตัว เพราะคีย์บอร์ดบางรุ่นมีไม่ครบ 88 คีย์)
- ทำแบบเดียวกันกับ F และ G

**3. ดริลล์ (`E_KEYFIND`) 5 นาที**
- รอบ 1: แอพบอกชื่อโน้ต (C, F, G เท่านั้น) 10 ข้อ
- รอบ 2: เพิ่ม D, E, A, B ทั้งหมด 14 ข้อ
- รอบ 3: สุ่มชื่อโน้ตและอ็อกเทฟ (เช่น "A ที่อยู่ต่ำกว่า Middle C") 10 ข้อ
- ตอบผิด: แอพแสดงตำแหน่งที่ถูกแล้วถามซ้ำท้ายรอบ ไม่บอกใบ้เกินครั้งละ 1 ข้อ

**4. เกณฑ์ผ่าน**
สุ่ม 10 ข้อถูกทั้งหมดภายใน 3 วินาทีต่อข้อ ใน 2 เซสชันคนละวัน

**5. ส่งเข้า spaced repetition**
`key:C`, `key:D`, ... `key:B` (ตำแหน่งคีย์ ทั้งชื่ออังกฤษและโด-เร-มี)

**6. เคล็ดลับการฝึก (โค้ช)**
"ไม่ต้องนับจากซ้ายสุด ให้มองหาป้ายกลุ่มดำก่อน แล้วค่อยหาคีย์ขาว วันนี้ลองหา C ทุกตัวแล้วอ่านออกเสียงว่า C ทุกครั้งที่กด"

## 11. Ear training รายละเอียด (ปรับจาก `prompt.md` 5.5)

### 11.1 ระดับ
- **E1**: เปรียบเทียบสูง–ต่ำ, ทิศทางทำนอง (ขึ้น/ลง/ซ้ำ)
- **E2**: Interval ภายในหนึ่งขั้นถึง 5th (ฟังแล้วเล่นบนเปียโน)
- **E3**: ไทรแอดเมเจอร์/ไมเนอร์
- **E4**: Interval ถึงอ็อกเทฟ
- **E5**: ทำนองสั้น 3–4 โน้ตเดินทีละขั้น แล้วขยายเป็นกระโดด (melodic dictation)
- **E6**: จังหวะ 1–2 บาร์
- **E7**: โปรเกรสชัน 4 คอร์ดที่ใช้เลขโรมัน (I IV V vi ก่อน แล้วเพิ่ม ii iii)
- **E8**: คอร์ดเซเวนท์และสแลชคอร์ด รวมการได้ยินเบสไลน์
- **E9**: ผสม: ฟังท่อนสั้น หาคีย์ โปรเกรสชัน และทำนอง (ใช้ในโปรเจกต์ 9.5)
ปลดล็อกตามด่านเรียน (E1–E2 ตั้งแต่ด่าน 1, E7 ตั้งแต่ด่าน 5) และฝึก **หลายระดับสลับกันในแต่ละสัปดาห์** ไม่รอให้ "จบ" ระดับหนึ่งก่อน

### 11.2 รูปแบบการตอบ
เล่นบนเปียโนจริง (MIDI) เป็นค่าเริ่มต้น หรือกดบนคีย์บอร์ดหน้าจอ หรือเลือกจากปุ่ม ทุกข้อให้ผู้ใช้เล่นเสียงที่ฟังซ้ำบนเปียโนก่อนตอบหรือหลังเฉลย (เชื่อมหูกับมือ)

### 11.3 ตัวช่วยถอดเพลง (Transcribe helper)
- วนลูปวลีสั้น, ปรับความเร็ว 50–100% โดยไม่เปลี่ยนระดับเสียง
- ใช้กับวลีที่แอพสร้างหรือที่ผู้ใช้ป้อนเองเป็นโน้ตก่อน (เฟสแรก)
- **การนำเข้าไฟล์เสียง (ต้อง time-stretch) เป็นฟีเจอร์เสริมภายหลัง** ไม่รวมในเฟสแรก และต้องเตือนเรื่องลิขสิทธิ์: ใช้ส่วนตัวเท่านั้น
- ตรวจคำตอบด้วยการเล่น: ผู้ใช้เล่นสิ่งที่คิดว่าได้ยิน แอพเล่นเทียบกับต้นฉบับ

### 11.4 สถิติ
ความแม่นยำแยกตามชนิด (interval แต่ละแบบ, ชนิดคอร์ด, ระดับขั้นในโปรเกรสชัน) และเวลาตอบ ใช้เลือกโจทย์ที่ควรฝึกต่อ

## 12. การวัดผลว่า "เก่งขึ้นจริง" และการทดสอบ

### 12.1 Benchmark ทุก 2 สัปดาห์ (โจทย์ชุดเดียวกัน ชุดคงที่ ไม่ซ้ำกับแบบฝึกหัด)
1. ความเร็วระบุโน้ต (โน้ต/นาที และความถูก)
2. ระดับ sight reading สูงสุดที่เล่นสะอาดในรอบเดียว
3. ความนิ่งของจังหวะ (SD ms) ที่ 70 bpm
4. จำนวนการเปลี่ยนคอร์ดถูกใน 60 วินาที
5. ความแม่นยำ ear training ชุดมาตรฐาน
แสดงกราฟเทียบกับวันแรก (baseline) เพื่อให้ผู้ใช้เห็นผลลัพธ์จริง และใช้เป็นข้อมูลปรับค่าตัวเลขต่างๆ ในเอกสารนี้ (เช่น เกณฑ์เวลา ช่วงทบทวน) ตามที่ได้ผลกับผู้ใช้คนนี้

### 12.2 การทดสอบโค้ด
- Unit test ตัวสร้างโน้ต: ทุกบทที่สร้างต้องอยู่ในตำแหน่งมือและช่วงเสียงของระดับนั้น ไม่มีระยะที่ระดับนั้นห้าม (สุ่ม 1,000 บทต่อระดับ)
- Unit test กฎผ่าน: ramp tempo, clean run, ผ่านใน 2 วัน, การปลดล็อก, สถานะกล่อง spaced repetition
- Unit test การชดเชย latency และการตัดสินเวลา ด้วยเหตุการณ์ MIDI จำลอง
- ตรวจเนื้อหาบทเรียน: ทุกบทมีฟิลด์ครบ, ไม่มีข้อความที่ละเมิดลิขสิทธิ์ (ไม่มีเนื้อร้องหรือโน้ตของเพลงจริง)

### 12.3 ในสองสัปดาห์แรกของการใช้งานจริง
ให้ Claude Code เตรียมหน้าจอส่งออกบันทึกการใช้งานเป็น JSON เพื่อให้ผู้ใช้ส่งกลับมาปรับค่าได้

## 13. ข้อจำกัดและสิ่งที่ยังไม่รู้
- หลักฐานจากการวิจัยเรื่องการสอนเปียโนผู้ใหญ่มือใหม่มีน้อย ส่วนใหญ่มาจากครูและเว็บสอน ให้ถือเกณฑ์และตัวเลขเป็นค่าเริ่มต้นแล้วปรับตามผลวัดจริง
- ยังไม่ยืนยันว่า Badger C-918 ส่ง velocity จริงหรือไม่ มีกี่คีย์ จึงออกแบบไม่ให้เงื่อนไขผ่านขึ้นกับ dynamics
- Bluetooth MIDI อาจหน่วงมาก จึงมี latency calibration แยกตามช่องทาง
- ข้อมูลว่า Hello! Project/AKB48 ใช้ฮาร์โมนีแบบไหนมีจำกัด ดูหัวข้อ 9.2
- เวลาที่ประมาณในแต่ละด่านเป็นเพียงกรอบคร่าวๆ ห้ามสัญญา
