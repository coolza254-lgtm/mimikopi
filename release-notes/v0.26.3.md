รุ่น 0.26.3: โน้ตไหลแนวนอนเต็มหน้าจอ

- ระหว่างเล่นหรือฟังตัวอย่างในโหมดโน้ตไหล เมื่อหมุนแนวนอน พื้นโน้ตและเปียโนจะใช้พื้นที่เต็มจอ
- ย้ายปุ่มหยุด สถานะ และสวิตช์ชื่อบนคีย์เป็นแถบเล็กซ้อนด้านบน ไม่มีแถบขาวควบคุมด้านล่าง
- ซ่อนแถบสถานะและแถบนำทางระบบขณะเล่น ปัดจากขอบจอเพื่อเรียกแถบระบบชั่วคราวได้
- ขยายภาพถึงขอบจอ โดยเว้นตำแหน่งรอยบากสำหรับปุ่มควบคุม
- กดหยุด/ปุ่มย้อนกลับ หรือหมุนกลับแนวตั้ง จะคืนรูปแบบหน้าปกติ
- เปิด/ปิดชื่อบนคีย์และผลตัดสินการเล่นยังทำงานเหมือนเดิม

วิธีลอง: เปิดเพลง → โน้ตไหล → เริ่มเล่น แล้วหมุนมือถือแนวนอน
