รุ่น 0.26.4: ฝึกหูแบบ B — ฟัง พัก ตอบ เฉลย

- ปรับหน้าฝึกหูตามแบบ B ที่เลือก แสดงช่วงคอร์ดนำ → พัก → โจทย์ → ตอบ → เฉลย ชัดเจน พร้อมรูปแบบแนวนอนและธีมมืด
- เว้น 0.9 วินาทีหลังคอร์ดนำก่อนเสียงโจทย์ และรอเสียงโจทย์จบก่อนรับคำตอบ
- แอปไม่เล่นเสียงตามคีย์ที่กดตอบ ทั้ง MIDI และมือถือ ลดเสียงซ้อนกับโจทย์หรือเฉลย
- หลังตอบ รอปล่อยคีย์และแป้นเหยียบ แล้วเว้นจังหวะก่อนเล่นเฉลย ปุ่มฟังซ้ำและข้อถัดไปไม่แทรกระหว่างเสียง
- เมื่อต่อ MIDI ซ่อนปุ่มโน้ตบนจอ ตอบโน้ต/ทำนอง/จังหวะด้วยเปียโนได้ ส่วนคำถามเลือกคอร์ดหรือทางเดินคอร์ดแสดงตัวอักษรคีย์สำหรับเลือกคำตอบ
- เฉลยจบแล้ว กด C บนเปียโนเพื่อไปข้อถัดไปได้ ถอด MIDI แล้วกลับมาใช้ปุ่มตอบบนมือถืออัตโนมัติ
- หยุดเสียงและงานที่ค้างเมื่อออกจากหน้าฝึก กลับเข้ามาจะเริ่มโจทย์ที่ยังไม่ตอบใหม่อย่างเป็นลำดับ
- เนื้อหาโจทย์ จังหวะที่ใช้ให้คะแนน และเกณฑ์ผ่านเดิมยังเหมือนเดิม

วิธีลอง: เปิดฝึกหู → ฟังคอร์ดนำและช่วงพัก → ฟังโจทย์ → ตอบ → ปล่อยคีย์และแป้นเหยียบ → ฟังเฉลยให้จบ
หมายเหตุ: แอปปิดได้เฉพาะเสียงที่แอปสร้างเอง หากเปียโนจริงมีลำโพงในตัว เสียงจากเปียโนยังขึ้นกับการตั้งค่าที่เครื่อง
